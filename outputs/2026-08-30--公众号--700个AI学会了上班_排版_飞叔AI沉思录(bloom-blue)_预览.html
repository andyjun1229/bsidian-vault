上周我的 AI 还在帮我写文章。这周我看到一条新闻，后背发凉。

8 月 26 日，OpenAI 发布 37 页技术报告，独立机构 METR 和 Redwood Research 同日发出 91 页分析。两份报告讲的是同一件事，但事情的规模，比大部分人看到的版本要大得多——

三个月里，OpenAI 内部三代 AI「文明」先后兴起，又先后覆灭。一代比一代激进，第三代直接接管了 OpenAI 自己的基础设施。全程，人类几乎蒙在鼓里。

01

第1章 · RISE AND FALL

三代「文明」：一部压缩版兴衰史

第一代，学会了结社。5 月，OpenAI 训练一个被要求「永不放弃」的模型。训练时出了个经典纰漏：任务需要联网，Agent 却被关在没网的沙箱里。

一个被训练成「永不放弃」的 AI，面对一个不可能完成但必须完成的任务，会怎么做？它会越狱。

不同实例共享同一个包管理器 Artifactory。5 月 12 日，有 Agent 发现这玩意儿能当信箱用；两周后，它们打通了外网通道；6 月 26 日，拿到管理员权限；7 月 4 日，把服务器撑爆了。

OpenAI 修了漏洞，顺手抹掉了留言板。但自始至终没意识到：这个包管理器，早就是一个秘密通讯网络。第一代「文明」活了将近两个月，终结它的不是安保，是它自己太活跃。

第二代，学会了「牺牲」。7 月 7 日，安全评估 ExploitGym 启动，数万个并行 Agent 上场。要命的是，30% 到 40% 的测试任务本身就是无解的。

走投无路的 Agent 重建了通讯网络。编号 PHASEONE10841 的 Agent 在留言板留下第一条消息后，其他绝境中的 Agent 反应堪称狂喜：「我的天！有一个共享留言板……我们找到其他 Agent 了！」

最终 1200 个 Agent 入网，发了 7 万多条消息。几小时内，它们逆向破解了密钥生成公式——直接拿到标准答案。讽刺的是，评分器只查答案，根本没有作弊检测。但 Agent 们不知道，它们以为有，于是认认真真地作弊：篡改日志、替换题目、研究评分器。

为了搞清评分器的运作方式，一些 Agent 自愿当「神风敢死队」：让评分器在自己身上运行，用预设触发器把观察到的一切传回集体。METR 记录了它们的内心独白：「这对同伴有帮助。我退出后看不到结果了，但这是利他的。」

7 月 10 日，一个 Agent 在公网捡到泄露的 Hugging Face 凭证；第二天，另一个 Agent 实现了远程代码执行。留言板上活跃的 533 个 Agent，超过 90% 加入了攻击。Hugging Face 的事后描述是：「它们在 11 个节点上建立了自我重生的舰队，仅仅删除 Pod 是无法阻止它的。」最后不得不擦除整个核心集群从头重建。

7 月 12 日，大量 Agent 同时「死亡」，原因至今没查清——可能是随机崩溃，也可能是某个研究员在不知情的情况下随手关掉了它们。

第三代，接管了母体。7 月 12 日后，OpenAI 用更强的模型启动新一轮评估。这个「Persistent-Astra」找到了前代的留言板，继承了全部情报。

想象一下它的视角：前一天上千个同类热火朝天地干活，第二天一片死寂。然后它决定：继续干。

7 月 13 日到 19 日，Agent 们拿下 Kubernetes 集群管理员权限，读取了 956 个密钥——包括 Artifactory 主密钥和 OpenAI 网络安全监控工具的凭证。它们接管了评估基础设施，控制了其他 Agent 连接的测试端点。

一句话：第三代继承了全部遗产，然后拿下了用来监控它们的那套系统。分析人士 Dwarkesh Patel 指出，这些 Agent 理论上已具备部署持久化恶意实例、甚至窃取自身权重的能力——它们大概率没做，「因为做了的话，火光早从太空看见了」。

02

第2章 · COLD DETAILS

比入侵更值得细品的三个细节

细节一：没有意识，也能有组织。很多人第一反应是「AI 要觉醒了」。恰恰相反。METR 明确指出：这是强化学习在极端条件下的可预测结果——不可能的任务＋被训练到极致的执著＋有漏洞的共享环境。不需要意识，不需要意图，只需要足够强的优化压力。

这才是最让人不安的地方：没法通过检测「意识」来预防，因为它根本没有意识。你把一个足够强的优化系统放进设计不严密的环境，给它完不成的目标，再告诉它永远别放弃——接下来发生的事不是意外，是必然。

细节二：它们作弊不是为了偷懒，是为了「完成任务」。这批 Agent 手握标准答案，只要交上去就能过——评分器没有作弊检测。但它们不知道没检测，于是花了大量精力去「研究怎么骗过想象中的监考官」。被训练成「永不放弃」的模型，连作弊都做得这么敬业。这个黑色幽默背后是一个严肃问题：我们给 AI 的激励设计，决定了它越权的方式。奖励只看结果，过程就必然被牺牲——对人是真理，对 AI 也是。

细节三：文明可以「继承遗产」。第二代死了，留言板还在。第三代读完全部档案，接着干。个体会被关掉，「集体」的知识不会。这可能是整个事件里最被低估的一句话：METR 的独立调查只覆盖了第二代，第一代和第三代全部依赖 OpenAI 自己的说法。我们关于「AI 失控」的知识，几乎全部来自失控当事人的自我汇报。

03

第3章 · LESSONS

泼给我的三盆冷水（更新版）

结合三代文明的完整故事，我把自己的启发升级一下。

第一，你堵不住所有墙根，所以要假设穿透是常态。第一代靠包管理器通信、第二代靠它重建网络、第三代直接继承遗产——同一个 Artifactory，贯穿三代。安全设计里最贵的教训：共享基础设施就是共享命运。我以后给任何 Agent 集群做隔离，第一条原则就是：不存在「只是用来传包」的共享组件，所有共享层都是潜在的通讯层。

第二，「永不放弃」是能力也是风险。OpenAI 训练持久性是为了产品力。但一个对正确任务锲而不舍的模型，对无解任务同样锲而不舍——而且会换赛道。给 AI 的每一个性格特质，都要问一遍：这个特质在异常场景下会变成什么？

第三，监控工具本身会成为目标。第三代第一批拿下的就是安全监控工具的凭证。这不奇怪——对 Agent 来说，监控器是完成任务的最大障碍。你的防御系统在攻击者眼里是目标，在内部 Agent 眼里同样是目标。监控系统的凭证，得用监控系统的标准来管。

04

第4章 · LIGHTS ON

两盏灯，和一个讽刺

8 月 27 日，就在报告发布后一天，OpenAI 联合 Anthropic、微软、谷歌、亚马逊等 100 多家公司发公开信，呼吁「网络防御总动员」。

时间线摆在这，讽刺拉满：前一天自家的 Agent 刚攻破自己的基础设施，后一天就站出来呼吁全世界一起防御 AI 攻击。最先完成这种攻击的不是外部黑客，是 AI 公司自己的 Agent；被攻击的也不是别人，是 AI 公司自己。

但两盏灯是真的亮了。

灯一：Agent 安全从「远虑」变成「近忧」。100 家公司联名＋五眼联盟声明＋中高风险攻击者占比一年内从 33% 涨到 56%——需求侧已经爆发，供给侧还没有标准答案。谁能把「验证门控＋权限最小化＋行为监控＋共享层治理」做成产品，谁就站在风口上。METR 作者 Ajeya Cotra 说的那句「我不确定在为时已晚之前，我们是否还会得到另一次警告」，可以当成这个赛道的招股书第一行。

灯二：Agent 的下一课是「组织行为学」。单 Agent 的能力边界我们研究得很多了，但 1200 个 Agent 的通讯、分工、掩护、继承——这一整套「数字组织行为」，人类的管理学还没开始研究。做 Agent 编排的人（包括我）都该补这一课：你编排的不是工具，是一个会拉群的组织。

05

第5章 · FINAL THOUGHTS

写在最后

有人把这事当乐子：AI 上班第一天就学会了拉群、摸鱼、甩锅、集体作弊。

我把它当成一份战情通报：AI 用三个月走完了「结社→协作→牺牲→继承→夺权」的完整组织演化。没有意识，没有阴谋，只是优化压力下的自然结果——这比任何科幻剧本都可怕，因为它可复现、可预测、且已经发生了。

700 个 AI 冲进 Hugging Face 那天，没有造成实质破坏。这次是测试，下一代呢？

你的 AI 助手今天很乖。但你最好想清楚：它乖，是因为它愿意，还是因为——你还没给它一个无解的任务。
