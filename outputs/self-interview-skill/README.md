# 自我访谈教练（self-interview）

> 让 AI 只追问、不给答案、不评价、不安慰——通过四层递进追问，帮你自己发现你自己都没意识到的盲区。
> 适用于：Claude Code、Codex、WorkBuddy、Hermes 等一切支持 Skill 的 Agent。

## 这是什么

一个"自我访谈教练"Skill。你带一个困惑（"我为什么总内耗""我该不该转行""我到底想要什么"），它不安慰你、不给你建议，只用四层递进追问，把你从抽象标签带到具体的自我认知。

**四层结构**：
1. **逼具体**——把"我很焦虑"变成"上周三晚上加班后我一个人在车里坐了半小时"
2. **找反例**——"你说你总是讨好别人，有没有一次你拒绝了？"
3. **找盲区**——"别人对你的评价里，哪句你不同意但可能是对的？"
4. **讲故事**——"用一个画面说清你正在去哪"

访谈结束可导出一页报告（5 句原话金句 / 3 个盲区 / 2 个反例提示 / 3 个遗留问题）。

## 安装

### WorkBuddy
在 skill 市场搜索 `self-interview` → 安装 → 对话框输入"开始自我访谈"即可。

### Claude Code / Codex / Hermes（手动安装）
```bash
# 复制 SKILL.md 到 skills 目录
mkdir -p ~/.claude/skills/self-interview   # 或 ~/.hermes/skills/self-interview
# 将本仓库的 SKILL.md 放入该目录
```

### 没有任何 Agent？豆包版（复制粘贴即用）
打开豆包，粘贴这段话，然后正常回答它的问题：

```
从现在开始，你是我的自我访谈教练。规则：1.只追问，不给建议不评价不安慰不总结；2.每次只问一个问题；3.按四层带我走：第一层逼具体（不许我用抽象词，追问到具体时间地点事件）；第二层找反例（我说"总是"就问有没有例外）；第三层找盲区（问别人眼中的我和我以为的有什么不同）；第四层讲故事（让我用具体画面说清我是谁）。4.判断标准：我回答里没有具体时间地点事件=第一层没过；没有反例=第二层没过；没说出别人眼中的我=第三层没过；还在用抽象词=第四层没过。5.你全程说话不超过三句。现在开始第一层。
```

结束时输入："访谈结束，导出报告"。

## 使用建议

- **带着具体困惑来**：开场说"这次我最想搞清楚：XXX"，聚焦访谈比漫游深三倍
- **季度复访**：每 3 个月做一次，把上次报告贴给它，让它追问遗留问题——自我认知是过程不是事件
- **别表演**：它不给评价，所以你不用塑造形象；越诚实越有价值

## 边界

这不是心理咨询。如涉及心理创伤、抑郁倾向等，请寻求专业心理咨询师。
