# 成就事件分析模板

> 从你的成功中提取优势 | STAR-R深度解构法

---

## 为什么分析成就事件？

> **你的优势不是你以为的，也不是别人说的，而是你在不知不觉中反复使用的。**

成就事件是你**无意识使用优势**的证据。通过深度分析这些事件，你可以发现：
- 你真正擅长什么
- 你在什么情境下发挥最好
- 你的能量来源是什么
- 你的独特工作方式

---

## 第一步：收集成就事件

### 收集范围

不要只收集"大成就"，小成就同样有价值：
- 工作上的项目成功
- 学习上的突破
- 帮助他人的经历
- 克服困难的时刻
- 创造性的解决方案

## 第二步：STAR-R深度解构

对每个重要事件，进行以下分析：

### S - Situation（情境）

```
当时是什么背景？
- 时间：什么时候？
- 地点：在哪里？
- 环境：什么组织/团队/情境？
- 挑战：面临什么困难/问题？
- 资源：你有什么支持/限制？
```

### T - Task（任务）

```
你要完成什么？
- 目标：具体要达成什么？
- 角色：你承担什么职责？
- 期限：什么时间完成？
- 标准：什么算成功？
```

### A - Action（行动）

```
你具体做了什么？（最关键的部分）
- 第一步：你首先做了什么？
- 关键行动：最重要的行动是什么？
- 独特方法：你用了什么"独特的方法"？
- 克服困难：遇到障碍时你怎么做？
- 协作：你如何与他人合作？
```

### R - Result（结果）

```
结果如何？
- 定量结果：具体数字/成果？
- 定性结果：影响/反馈/评价？
- 超预期：有什么超出预期的部分？
- 长期影响：这件事带来了什么后续？
```

### R - Reflection（反思）

```
深度反思：
1. 这件事中，哪部分你做得最轻松？
2. 哪部分别人觉得难，你觉得自然？
3. 你当时用了什么"独特的方法"？
4. 如果重来，你会复制什么？改变什么？
5. 这件事让你感到"这就是我"的瞬间是？
6. 你用了什么能力/优势？
7. 你的能量来源是什么？
8. 什么环境让你发挥最好？
```

## 第四步：优势命名与验证

### 命名你的优势

**用行为描述，而非标签**：

❌ 不好的命名：
- "我很有领导力"
- "我很擅长沟通"
- "我逻辑思维强"

✓ 好的命名：
- "我能在混乱中快速识别关键问题，并组织大家解决"
- "我能让复杂的技术概念变得让非技术人员理解"
- "我能在高压下保持冷静，找到突破口"

**命名模板**：
```
我能在____（情境）中，____（行动），从而____（结果）。
```

### 验证你的优势

**四种验证方式**：

```
1. 回忆验证
   - 过去哪些事证明了这个优势？
   - 至少找到3个例子

2. 他人验证
   - 问3个人："你觉得我最擅长什么？"
   - 他们的回答与你的分析一致吗？

3. 测评验证
   - VIA优势测评结果是否支持？
   - 大五人格结果是否支持？

4. 实验验证
   - 刻意在新情境中使用这个优势
   - 观察是否同样有效
```

## 完整示例

### 事件描述

```
事件：领导跨部门项目，3个月内上线新产品

S：公司要快速进入新市场，需要技术、设计、市场部门协作
T：作为项目经理，协调3个部门，按时交付
A：
- 第一周：与每个部门一对一沟通，理解他们的困难和优先级
- 建立每周同步会议，但控制在30分钟内
- 发现技术部门和市场部门对"完成"定义不同，组织工作坊统一标准
- 当进度落后时，不是施压，而是问"需要什么支持"
R：按时上线，用户反馈良好，团队满意度高
R：
- 我最轻松的部分是理解不同部门的需求
- 别人觉得协调很难，我觉得很自然
- 我的独特方法是"先理解，再协调"
- 我感到"这就是我"的瞬间是看到各部门从对立到合作
- 我用的能力：同理心、系统思考、沟通协调
- 我的能量来源：看到团队从混乱到有序
- 最佳环境：有挑战但支持性的环境
```

### 优势提取

```
核心优势：
1. 跨部门协调：能理解不同部门的语言和需求，促进合作
2. 系统思考：能看到项目的全局和各部门的关联
3. 同理心沟通：能感知他人的困难和情绪，调整沟通方式

组合优势：
"我能在复杂的跨部门项目中，通过深度理解各方需求，
建立有效的协作机制，从而推动项目顺利完成。"
```

## 常见优势模式参考

### 分析型优势

```
特征：喜欢拆解问题、寻找规律、逻辑推理
成就事件：解决复杂技术问题、优化流程、发现漏洞
适合场景：研究、分析、策略规划
典型描述："我能在复杂信息中快速找到关键模式"
```

### 连接型优势

```
特征：擅长整合不同领域、建立关系、促成合作
成就事件：跨部门项目、资源整合、牵线搭桥
适合场景：项目管理、商务拓展、组织协调
典型描述："我能让不同背景的人为了共同目标合作"
```

### 表达型优势

```
特征：善于传递思想、影响他人、创造内容
成就事件：演讲、写作、教学、谈判
适合场景：培训、营销、创作、咨询
典型描述："我能让复杂的概念变得简单易懂"
```

### 执行型优势

```
特征：专注落地、确保完成、注重细节
成就事件：按时交付、解决突发问题、建立系统
适合场景：运营、执行、项目管理
典型描述："我能在压力下保持冷静，确保事情完成"
```
