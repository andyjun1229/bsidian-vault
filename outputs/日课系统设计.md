# 日课系统设计

> 从曾国藩到现代自我追踪 | 持续觉察的实践框架

---

## 为什么需要日课？

> **认识自己不是一次性的顿悟，而是持续的觉察。**

曾国藩的"日课十二条"之所以有效，是因为它把模糊的"修身"变成了**可追踪、可验证、可调整**的系统。

---

## 日课设计的四层架构

```
┌─────────────────────────────────────┐
│  第一层：基础监测层（每天必做）        │
│  → 记录行为、情绪、能量              │
├─────────────────────────────────────┤
│  第二层：模式识别层（每周回顾）        │
│  → 发现规律、验证假设                │
├─────────────────────────────────────┤
│  第三层：假设实验层（每月尝试）        │
│  → 主动测试、收集数据                │
├─────────────────────────────────────┤
│  第四层：意义整合层（每季反思）        │
│  → 连接价值观、调整方向              │
└─────────────────────────────────────┘
```

---

## 第一层：基础监测层（每天5-10分钟）

### 核心问题

```
1. 今天什么时候我感觉"这就是真正的我"？
2. 今天什么时候我感觉"我在伪装/勉强"？
3. 今天我的能量高峰和低谷分别在什么时候？
4. 今天有什么让我完全沉浸、忘记时间的事情？
```

### 记录模板

```
日期：____年__月__日
━━━━━━━━━━━━━━━━━━━
【能量曲线】
高峰：____（时间：____，活动：____）
低谷：____（时间：____，活动：____）

【真实时刻】
✓ 什么时候感觉"这就是我"：____
✗ 什么时候感觉"在伪装"：____

【心流时刻】
今天完全沉浸的事情：____
持续了多久：____

【情绪记录】
主要情绪：____
触发事件：____
身体感受：____

【明日假设】
如果____，可能会更好？
```

### 记录工具推荐

| 工具 | 优点 | 适合人群 |
|------|------|---------|
| **纸质笔记本** | 无干扰、有仪式感 | 喜欢手写、需要远离屏幕 |
| **手机备忘录** | 随时随地、快速 | 忙碌、追求效率 |
| **Notion/飞书** | 可统计、可搜索 | 喜欢数据分析 |
| **flomo/浮墨** | 极简、标签系统 | 喜欢碎片化记录 |

## 第二层：模式识别层（每周30分钟）

### 每周回顾模板

```
本周日期：____至____
━━━━━━━━━━━━━━━━━━━

【能量模式】
- 我的能量高峰通常在：____
- 我的能量低谷通常在：____
- 规律发现：____

【真实时刻】
- 本周最"是我"的时刻：____
- 本周最"不是我"的时刻：____
- 共同点：____

【心流模式】
- 本周心流时刻：____次
- 触发心流的活动类型：____
- 规律发现：____

【优势使用】
- 本周最常使用的优势：____
- 使用场景：____
- 效果：____

【困惑与挑战】
- 本周最大的困惑：____
- 可能的解释：____

【下周调整】
- 我想尝试：____
- 我想避免：____
```

### 数据分析（可选）

如果你用电子工具记录，可以统计：
- 能量高峰的时间分布
- 心流时刻的活动类型
- 情绪与活动的关联
- 优势使用的频率

## 第三层：假设实验层（每月）

### 实验设计模板

```
实验编号：____
日期：____
━━━━━━━━━━━━━━━━━━━

【假设】
我认为：____

【实验设计】
我将：____
持续：____天

【成功指标】
如果假设成立，我应该观察到：____

【失败信号】
如果假设不成立，我可能会观察到：____

【实际结果】
发生了什么：____

【结论】
□ 假设验证
□ 假设推翻
□ 需要更多数据

【下一步】
基于结果，我将：____
```

### 示例实验

```
实验1：晨间写作
假设：我早上写作效率更高
设计：连续2周，每天早上6:30-7:30写作
指标：字数、心流次数、事后满足感
结果：验证/推翻/调整

实验2：深度工作块
假设：我需要无打扰的2小时才能进入深度工作
设计：每天设置2小时"勿扰模式"，关闭通知
指标：任务完成质量、心流时长
结果：验证/推翻/调整
```

## 第四层：意义整合层（每季2-4小时）

### 季度反思模板

```
季度：____年Q__
━━━━━━━━━━━━━━━━━━━

【自我认知进展】
- 这三个月，我更清楚"我是谁"了吗？
- 我对自己有什么新发现？
- 什么认知被验证/推翻？

【核心价值观】
- 我的核心价值观是什么？（列出3-5个）
- 排序：____ > ____ > ____ > ____ > ____
- 我现在的选择与这些价值观一致吗？

【优势发展】
- 我的标志性优势是什么？
- 我如何更多地使用它们？
- 有什么优势需要平衡？

【方向调整】
- 有什么我需要"放弃"的（不是真正想要的）？
- 有什么我需要"坚持"的（即使困难）？
- 下季度的重点是什么？

【感恩与欣赏】
- 这三个月我最感恩的是什么？
- 我欣赏自己的什么？
```

## 避免的陷阱

| 陷阱 | 表现 | 对策 |
|------|------|------|
| **完美主义** | 一天没记就放弃 | 允许"补记"，允许简化 |
| **过度分析** | 记了但不行动 | 每周必须有1个行动调整 |
| **自我批判** | 记录变成自我批评 | 用观察者视角，而非评判者 |
| **孤立记录** | 只记不与人交流 | 定期与信任的人分享发现 |
| **形式化** | 为了记而记，不思考 | 每周问：我发现了什么新模式？ |

## 进阶技巧

### 1. 主题日记

除了每日记录，可以定期写主题日记：
- **优势日记**：追踪优势使用
- **感恩日记**：每天3件感恩的事
- **恐惧日记**：记录并面对恐惧
- **决策日记**：记录重要决策的过程和结果

### 2. 对话日记

与内心的自己对话：
```
批判者："你不够好"
观察者："我注意到自我批评出现了"
探究者："这个批评想保护我什么？"
智者："即使有不足，我也可以接纳并成长"
```

### 3. 身体觉察

日课不仅是思维记录，还包括身体感受：
- 情绪在身体的哪个部位？
- 紧张时身体有什么感觉？
- 放松时身体有什么感觉？

## 推荐工具组合

### 极简版（适合初学者）
- 纸质笔记本 + 每天3句话
- 每周回顾用模板

### 标准版（适合进阶者）
- Notion/飞书多维表格（自动统计）
- 每日记录 + 每周回顾 + 每月实验

### 专业版（适合深度实践者）
- 自定义数据库（追踪多维度数据）
- 数据可视化（能量曲线、情绪分布）
- 定期与教练/咨询师回顾
