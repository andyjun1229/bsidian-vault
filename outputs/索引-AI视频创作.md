## 综合工作流

```
① 逛 LibTV Skill Hub → 挑方向（甲木/摸鱼的经验：先选 Skill 再动手）
② 选 Skill 或自建 Skill
   ├─ 摸鱼法：封装整条流水线顺序
   └─ 甲木法：6创意方案 → 5-6镜分镜 → 逐镜头视听提示词 → 关键帧确认 → 整片生成
③ Agent 先确认需求（角色性别/比例/品牌名）→ 出角色方案 → 锁定资产定妆照
④ 分镜故事板确认（铅笔线稿+景别/机位/角色动作标注）
⑤ 逐段生成视频
⑥ 发现问题 → Agent 定位具体片段 → 只重做问题段
⑦ 合成收尾（ASR字幕 / BGM / 落版字卡）
```

## LibTV 关键能力清单

| 能力 | 说明 |
|------|------|
| Skill Hub | 100+ Skill，7 个方向（影视/广告/短剧/动漫/自媒体/MV），创作者有 1000 万激励金 |
| 资产定妆照（锚点） | 每样东西先单独生成，停等确认，满意才进镜头 |
| 分镜故事板 | 铅笔线稿 + 运镜标注，确认后才进视频生成 |
| 画布双视图 | 故事板视图（验收）↔ 工作流视图（改节点），一键切换 |
| 返工颗粒度 | Agent 定位问题段，只重做问题段，其他保留 |
| 对话→Skill | 直接说"帮我把对话总结成 skill"，自动提炼 |
| CLI 安装 | 发给 coding agent 即可接入 |
| 自建 Skill | Markdown 写规则，创建的 Skill 可反复调用 |
