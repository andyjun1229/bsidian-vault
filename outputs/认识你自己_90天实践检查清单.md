# 认识你自己：90天实践检查清单

> 基于[[outputs/认识你自己_对话整理|对话整理]]的可执行步骤

---

## 📋 第1-30天：收集期

### 第1周：测评与记录启动

- [ ] **Day 1**: 完成VIA优势测试（viacharacter.org）
  - 记录你的前5项标志性优势
  - 保存测试报告

- [ ] **Day 2**: 完成大五人格测试（understandmyself.com）
  - 记录5个维度的分数
  - 思考：哪个维度最让你意外？

- [ ] **Day 3-7**: 开始每日记录（极简版）
  ```
  日期：____
  【能量高峰】____（时间+活动）
  【能量低谷】____（时间+活动）
  【真实时刻】今天什么时候感觉"这就是我"？
  ```

### 第2周：成就事件收集

- [ ] 列出过去3-5年**最有成就感的10件事**
  - 不要过滤，先全部列出
  - 可以是工作、学习、生活任何方面

- [ ] 列出**最沉浸其中的10件事**
  - 那些让你忘记时间的事情

- [ ] 列出**别人特别感谢你的10件事**
  - 你帮别人解决了什么问题？

### 第3周：外部反馈

- [ ] 问3个朋友/同事："你觉得我最大的优点和缺点是什么？"
  - 记录他们的回答
  - 注意：哪些是你没想到的？

- [ ] 问1个导师/前辈："你觉得我适合什么样的工作？"
  - 记录他们的建议

### 第4周：初步整理

- [ ] 整理所有收集到的信息
- [ ] 初步识别：反复出现的主题是什么？
- [ ] 写下3个"可能的假设"关于你的优势

---

## 🔍 第31-60天：分析期

### 第5周：深度解构成就事件

- [ ] 选择5个最重要的成就事件
- [ ] 对每个事件进行STAR-R分析：
  ```
  S - Situation（情境）：当时什么背景？
  T - Task（任务）：你要完成什么？
  A - Action（行动）：你具体做了什么？
  R - Result（结果）：结果如何？
  R - Reflection（反思）：你用了什么能力？
  ```

### 第6周：模式提取

- [ ] 分析5个事件的共同点：
  - 反复使用的能力类型？
  - 偏好的工作方式？
  - 能量来源？
  - 最佳环境？

- [ ] 用行为描述命名你的优势：
  - ❌ "我很有领导力"
  - ✓ "我能在混乱中快速识别关键问题，并组织大家解决"

### 第7周：假设实验设计

- [ ] 设计2个"假设实验"验证你的优势：
  ```
  假设：____
  实验设计：____
  持续时间：____
  成功指标：____
  ```

### 第8周：周回顾习惯建立

- [ ] 建立每周回顾模板（30分钟）：
  ```
  本周模式发现：
  - 我在什么情境下最自信？
  - 什么活动让我事后感到充实？
  - 我与什么人相处时最放松？
  - 下周调整：____
  ```

---

## ✅ 第61-90天：验证期

### 第9-10周：执行假设实验

- [ ] 执行实验1，记录结果
- [ ] 执行实验2，记录结果
- [ ] 根据结果调整优势命名

### 第11周：核心价值观明确

- [ ] 列出你最重要的5个价值观
  - 回顾：哪些时刻你感到"这就是对的"？
  - 排序：哪个是绝对不可妥协的？

- [ ] 评估：你当前的生活与这些价值观一致吗？

### 第12周：行动计划制定

- [ ] 制定"做回自己"的行动计划：
  ```
  我的核心优势：____
  我的核心价值观：____
  
  短期行动（1-3个月）：
  1. ____
  2. ____
  3. ____
  
  中期目标（3-12个月）：
  1. ____
  2. ____
  
  长期方向（1-3年）：
  1. ____
  ```

### 第13周：总结与展望

- [ ] 写一篇"给自己的信"：
  - 这90天我发现了什么？
  - 我对自己的认识有什么变化？
  - 接下来我想深入探索什么？

- [ ] 规划下一个90天的重点

---

## 🔄 持续实践（90天后）

### 每日（3-5分钟）
- [ ] 记录能量曲线
- [ ] 记录一个"真实时刻"

### 每周（30分钟）
- [ ] 周回顾：模式发现 + 下周调整
- [ ] 自我对话：30分钟无干扰反思

### 每月（2小时）
- [ ] 深度反思：假设验证 + 实验设计
- [ ] 成就事件分析（深度解构一件事）

### 每季（半天）
- [ ] 价值观对齐检查
- [ ] 方向调整

### 每年（1天）
- [ ] 全面回顾：成长轨迹
- [ ] 新年方向设定

## 💡 常见问题应对

| 困难 | 对策 |
|------|------|
| 没时间记录 | 从3句话开始，哪怕只有1句话 |
| 忘记做测评 | 设置手机提醒，或找朋友一起做 |
| 分析时困惑 | 先放一放，下周再看 |
| 实验失败 | 失败也是数据，调整假设再试 |
| 想放弃 | 回顾初衷，或降低标准继续 |
