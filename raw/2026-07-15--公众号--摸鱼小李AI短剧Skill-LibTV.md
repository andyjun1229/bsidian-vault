# 我把做 AI 短剧踩过的坑，做成了一个能反复升级的 Skill

原创 摸鱼小李
2026年7月15日 15:29 上海

## 01 从一个想法开始

最近看了周星驰的《功夫女足》，又想起喜剧的内核是悲剧，于是想做这种类型的小短片。

之前一直用 LibTV 做视频。但要么在网页里做，节点多了连线特别累还容易乱；用官方的 CLI 跑，虽然可以用其他 AI 来自动化跑，但少了实时网页版的画面反馈和交互，改起来也特别麻烦。

直到内测到了 LibTV 的全新功能——接入了自己的 Agent、Skill 能力，以及故事板页面。

**成品示例：** 留守老人组队赶野猪（01:13）
故事：野猪闯进村子，子女不在身边，留守老人自己想办法赶跑野猪。表面是幽默的组队打怪，但热闹散去后又回到一人一屋的孤灯的悲剧内核。

## 02 Skill Hub：先挑方向

做片子前先逛 Skill Hub。LibTV 邀请了 200+ 专业创作者，打造了首批 100+ 专业视频 Skill，覆盖广告、短剧、品牌创意、自媒体方向。

**工作流：**
1. 先挑方向，再顺着往下做
2. 这条片子加了两个公开 Skill：**杜琪峰站位风格** 和 **岩井俊二电影美学**
3. Agent 没有马上开工，先指出两套美学在流程上有冲突
4. 最终选择：整体以岩井的高调悲伤感为主，杜琪峰只用在组队站位镜头
5. 方向定下来后，才把故事顺成完整剧本
6. 跟着剧本准备人物多视图、环境、道具和声音
7. 第一轮场景图太精致像度假村 → 改成贫困破旧农村环境，保留逆光 → Agent 复述确认后重做

**关键经验：** "指着画面改"比扔一句"帮我优化"靠谱得多。

## 03 故事板：把流程摊开

素材固定之后才去看故事板。故事板把镜头顺序、人物站位和画面构图摊开在一张页面里。

**操作习惯：**
- 节点关系搞不清时切回工作流看依赖
- 调镜头顺序时切到故事板
- 两边随时切，不用重新加载
- 确认完故事板，视频节点才带上角色、站位和声音参考，逐段开始生成

## 04 自建 Skill：把顺序封装起来

创建 Skill 有两种路径：
1. 把一段满意的 Agent 对话直接转成 Skill
2. 自己写好规则后上传

**摸鱼小李自建的"短剧创作系统"：**
封装的是做漫剧时的顺序（不是一句提示词，是一套工作流）：

```
从故事种子推方向
→ 定剧情
→ 锁人物、场景和声音
→ 确认故事板
→ 最后才进视频生成。
```

**用同一套 Skill 再跑一条：**
之前用同一套自建 Skill 拍过另一条短片——三个不同年龄阶段的我，在同一间出租屋里相遇。

**关键经验：** 字节最新的音频模型已经接进 LibTV，通过提示词就能出完整的角色音频，是前期资产准备很省力的一环。

## 05 Agent：会组合，也会判断

片子剪完之后又顺手试了几个公开 Skill：

### CASE 01 - 狼人 × 吸血鬼脱口秀（01:00）
同时挂了两个 Skill：
- 一个定开放麦的段子节奏
- 一个给角色世界观
Agent 把它们重组后塞进同一场表演，效果超出预期。

### CASE 02 - 活人感女装带货（00:30）
输入一张试穿图和产品图，Agent 先分析产品细节，一步步对齐哪些卖点必须在视频里露出，确认完才出片。

### CASE 03 - 新中式面膜 TVC（00:40）
做完初版想延长 10 秒，Agent 判断不该在已经收尾的镜头后面硬接，而是在尾镜前插入新卖点，补好旁白再接回原结尾。**这个判断力让人印象深刻。**

## 写在最后

这一轮下来试了不少 Skill，有公开的也有自己建的，每个跑完都会冒出新想法。每做一个，下次遇到的坑就能自动绕开。Skill = 把踩过的坑变成能反复升级的资产。

核心平台：**LibTV**，它的 Skill Hub 有 200+ 创作者贡献的 100+ 专业视频 Skill。
