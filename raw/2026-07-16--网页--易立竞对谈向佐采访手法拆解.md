# 易立竞对谈向佐——采访手法拆解

## 采访风格特征

易立竞的采访风格以「犀利追问」「不回避敏感问题」「单刀直入」著称。她不会因为你面露难色就放过你，也不会因为对方是名人就客气。

## 关键追问手法

**手法1：直面矛盾**
易立竞会在采访前做大量功课，找出被采访者以往说过的话和现在做法的矛盾之处，直接摆到台面上问。

例如她对向佐的采访中，直接引用向佐过去采访中说的话，与现状对比，让他自己解释。

**手法2：不回避敏感词**
她不怕问「别人说你是靠家里」「你觉得自己演技差吗」这类问题。她认为观众有知情权，被采访者也应该有能力面对这些问题。

**手法3：沉默压力**
她会问完问题后长时间盯着对方不说话，等待对方主动填补沉默。这种沉默给被采访者很大心理压力，往往会迫使对方说出更多真实想法。

## 可借鉴的追问框架

```
你的过去说[XX]，现在做[YY]，这两个矛盾了——你怎么解释？
别人说你[负面评价]，你认同吗？
对于[敏感话题]，你的真实感受是什么？
（沉默等待）
```

## 适合自我访谈场景

易立竞式追问适合用来暴露「自我矛盾」——你说自己重视家庭但总是加班、你说自己崇尚自由但一直不敢离职、你说自己不在乎别人看法但处处讨好。直接问：「你说自己不在乎，那你为什么这么做？」
