## 视频摘要

本讲从大语言模型（LLM）的扩展定律讲起：模型参数量、训练算力、数据规模越大，测试损失越低。课程回顾了从 GPT-2 到 GPT-4 的演进，解释了少样本学习、零样本学习、思维链（Chain-of-Thought）推理，以及指令微调（Instruction Tuning）与基于人类反馈的强化学习（RLHF）如何催生 ChatGPT。

接着课程介绍「推理时间扩展」（inference-time scaling）：通过「Large Language Monkeys」项目，让模型对同一问题多次采样，再由验证器（verifier）选出正确答案，从而在不重新训练的情况下提升性能。

最后，课程从单轮聊天机器人过渡到 Agent 工作流，包括提示链（prompt chaining）、路由（routing）、并行化（parallelization）、协调器-工作者（orchestrator-worker）等模式，并以 Claude Code、Deep Research 等工具为例，说明 Agent 如何完成端到端任务。课程后半段讲解评分、作业、项目等教务安排。

### 2. 大语言模型的扩展定律

#### 2.1 规模带来性能提升

自 GPT-3 以来最惊人的观察是：模型参数量越大，性能越好。BERT、T5 已经不错，但参数规模提升后，模型表现明显更好。

扩展定律体现在三个维度：
1. **训练算力（Compute）**：x 轴为算力，y 轴为测试损失，算力越多，损失越低。
2. **数据规模（Dataset Size）**：数据越多，损失越低。
3. **参数数量（Parameter Count）**：Transformer 层数/参数量增加，损失降低。

从 2018 到 2024 年，模型规模几乎指数级增长：
- BERT：3.4 亿参数
- GPT-2：15 亿参数
- GPT-3：1750 亿参数
- PaLM：5400 亿参数
- GPT-4：估计达万亿级别

#### 2.2 大模型的能力涌现

模型变大后带来三类能力：
1. **基准性能持续提升**：自然语言、推理等 benchmark 成绩更好。
2. **少样本学习（Few-shot Learning）**：以前需要针对特定领域微调，现在只需给几个示例，模型就能按模板推理。
3. **涌现行为（Emergent Behavior）**：如推理能力只在较大模型中出现。

**零样本学习（Zero-shot）**：只给任务描述，不给示例，模型直接作答。例如「把英文翻译成法文：cheese」。

**少样本学习（Few-shot）**：在任务描述后给出几个输入-输出示例，再问新问题。GPT-3、PaLM 等模型在大量任务上展现出这种能力。

#### 2.3 思维链（Chain-of-Thought）

思维链是大模型最重要的涌现行为之一。

传统提示：给一个问题和示例答案，模型直接回答。

思维链提示：不仅给示例答案，还给推理过程。

例如数学题：
> Roger 有 5 个网球，又买了 2 罐，每罐 3 个。他现在有几个？

思维链示例会写出：「Roger 原本有 5 个；2 罐 × 3 个 = 6 个；5 + 6 = 11」。模型学会这种推理方式后，能解决新问题。

关键发现：
- 小模型（如 7B–8B）无法从思维链中受益。
- 大模型才能利用思维链提升数学等推理任务的表现。
- 思维链催生了近一年的推理模型（reasoning models）/思考模型（thinking models）进展。

### 3. 从预训练到 ChatGPT

#### 3.1 预训练

语言模型训练的第一步是预训练：让模型在所有文本、数据上做 next-token prediction。这是最简单的一步。

#### 3.2 高质量数据微调

预训练后的模型虽然学了世界统计规律，但缺乏对错判断、价值观和遵循指令的能力。

下一步是在更高质量的数据上微调，如书籍、创意写作、付费购买的精选数据。

#### 3.3 指令微调（Instruction Tuning）

指令微调数据通常由人类生成、角色模板和合成数据组成。模型学习「指令 → 问题 → 答案」的配对，例如：

> 请回答以下问题：氮气的沸点是多少？

也可以用思维链形式的指令微调，让模型学会分步推理。

数据的质量和通用性对模型这一阶段的表现影响极大。

#### 3.4 基于人类反馈的强化学习（RLHF）

RLHF 与指令微调的区别在于目标函数与数据构建方式：
- 公司花钱请人（有时是专家）对模型生成的多个答案打分。
- 根据人类偏好训练一个「奖励模型」（reward model）。
- 再用奖励模型引导 LLM 参数更新，使其生成更高奖励的回复。

奖励类型可以包括：正确性、有用性、具体性、无害性等，可以加权组合。

预训练 + 高质量微调 + 指令微调 + RLHF，是 ChatGPT 相比 GPT-3 实现跃迁的核心。

### 4. 推理时间扩展：Large Language Monkeys

#### 4.1 推理也是新前沿

大约一年半以来，「推理」（inference）本身也成为提升模型能力的战场。

Azalia 介绍了她实验室的「Large Language Monkeys」项目，灵感来自「无限猴子定理」：如果让猴子在打字机上随机打字足够久，理论上能打出莎士比亚全集。

#### 4.2 重复采样 + 验证器

具体做法是：
1. 对同一问题，让模型多次生成答案（并行采样）。
2. 用验证器/选择机制判断哪个答案正确。
3. 输出正确的那个。

验证器可以是单元测试（代码任务）、数学答案检查等。

实验发现：在数学和代码 benchmark 上，把每个问题的采样数从 1 提升到 10,000， smaller 模型的「覆盖率」（至少有一个正确答案的比例）可以超过 GPT-4o 的单次表现。

这说明：模型本身知道的比单次提问得到的更多。推理时间扩展可以在不修改模型参数的情况下释放更多能力。

#### 4.3 温度与多样性

通过调节 temperature 可以控制生成答案的多样性。温度太高（通常 > 1.2）会输出胡言乱语。研究者也在探索其他方法增加多样性。

#### 4.4 可验证领域 vs 不可验证领域

数学、代码等可验证领域容易应用；开放性问题需要训练 LLM 作为 Judge 或使用奖励模型，这是本课程会专门讲的内容。

### 5. 推理模型：DeepSeek、o1、Gemini

DeepSeek（2024 年 12 月发布）、Gemini Thinking 等模型的核心创新是：把推理时间扩展与微调/训练结合起来。

利用推理时间扩展，可以生成大量合成数据（例如已知答案的数学题、通过单元测试的代码题），再用这些数据微调模型，使其本身变强。

OpenAI o1 去年 9 月展示了：在 AIME（高难度数学 benchmark）上，随着测试时间计算量增加，pass@1 准确率呈对数线性提升。

推理模型的典型行为包括：
- **问题分析**：先理解问题。
- **任务分解**：把复杂任务拆成子任务。
- **自我验证/试错**：运行测试、使用计算器、判断答案。
- **自我修正与回溯**：发现错误后换一种方法。

这些能力一部分来自人类整理的训练数据，一部分来自微调与合成数据上的 RL。

### 6. 从 LLM 到 Agent

#### 6.1 单轮聊天 vs 端到端任务

LLM 聊天机器人通常是单轮或多轮对话，有趣但不一定完成实际任务。

Agent 工作流（如 Claude Code、Deep Research）能完成端到端目标：
- 被给定一个目标；
- 规划步骤；
- 与环境交互；
- 根据反馈修正；
- 直到完成或宣告失败。

Agent 通常需要：记忆、工具调用、规划、多步推理、自我改进。

#### 6.2 Agent 工作流模式

常见模式包括：

1. **提示链（Prompt Chaining）**：把任务拆成一串子任务依次执行。
2. **路由（Routing）**：根据任务复杂度决定走简单流程还是复杂流程。
3. **并行化（Parallelization）**：多个 LLM 同时处理不同关键词或子任务，再聚合结果。
4. **协调器-工作者（Orchestrator-Worker）**：一个中心 LLM 做规划，分派给多个子调用。
5. **评估器/裁判（Evaluator/Judge）**：用 LLM 作为裁判判断方案是否可接受。
6. **验证器（Verifier）**：在可验证领域（如代码）运行单元测试等检查。

#### 6.3 编码 Agent

编码 Agent（如 Claude Code、Codex）通过自然语言指令就能修改文件、搜索代码、运行终端命令、根据输出继续迭代。

这种循环去年还不太可靠，今年因模型能力更强、RL 训练更有效而变得可用。在可验证奖励（如单元测试）明确的领域，RL 训练效果特别好。

编码 Agent 最适合：重复性任务（代码迁移、版本升级、重构）、数据工程、单元测试生成等。

#### 6.4 客户支持 Agent

客户支持是 Agent 另一个高落地场景：
- 实时语音转录；
- 知识库问答（Knowledge Assist）；
- 智能回复建议；
- 通话摘要。

#### 6.5 研究 Agent 与 AI 科学家

复杂主题的综合报告可以由 Agent 完成：
1. 识别相关参考文献；
2. 判断哪些相关；
3. 总结每篇内容；
4. 合成完整文章。

更进一步，研究 Agent 开始扮演「AI 科学家」角色：
- 头脑风暴提出研究想法；
- 迭代实验设计；
- 辅助论文写作。

虽然模型仍会幻觉，但它们能提出人类可能想不到的跨领域想法，是极好的头脑风暴工具。

### 7. 课堂问答精选

**问：推理和思维链是训练出来的，还是提示工程偶然发现的？**

答：思维链最初是涌现行为，不是人为设计的。GSM8K 论文最先展示迹象，PaLM 等更大模型上效果更显著。但现在的推理模型是被明确训练来思考的。未来模型会融合两者，自动判断何时需要深度推理。

**问：重复采样与穷举所有可能答案有什么区别？**

答：答案空间巨大，无法穷举。10,000 次采样对于 IMO 级别难题来说其实很小，但已经能让小模型解决很多难题。这是高度采样高效的。

**问：没有验证器的领域怎么办？**

答：这是开放问题。课程会专门讲 verifier 与 LLM-as-Judge。

**问：不同模型分别负责推理和最终答案生成是否可行？**

答：通常推理能力随模型规模增长。可以用大模型生成推理轨迹，再用小模型总结答案。但模型往往更偏好自己的轨迹。
