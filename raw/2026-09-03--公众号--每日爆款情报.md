## 1. Claude Code 派活实战：我只负责点合并（迭代器 09-01）
**爆款要素**：标题反差（人只点合并）+ 数字结果（2852行→12模块、三天、零回归）；结构=3步配置→3个真实踩坑→金句收尾「AI是外包团队，你只看交付」。
**可复用**：① 子代理=一个md文件放 `.claude/agents/`，description 写具体触发场景，tools 最小权限；② `git worktree add` 隔离并行任务，话术模板「在 worktree X 基于 Y 完成Z，每文件一commit，完成开PR」；③ 铁律：CI绿≠交付达标，拿原始产物核对，合并闸门留给人。
**落地**：与你完全同频。照此结构写《我用 Hermes 把每日情报跑成无人值守流水线》，过程即内容。

## 2. 不只是聊天框：12 个容易被忽略的高效命令（AI算法之道 09-02）
**爆款要素**：标题公式「不只是X：N个被忽略的Y」（否定常识+数字清单）；开头点破「效率差距不在提示词，在上下文管理」；每条=痛点场景→命令→实例。
**可复用**：① `#`开头发消息即沉淀规则进 CLAUDE.md；② `/compact 保留XX决策，忽略XX`必须带聚焦指令；③ 重复提示升级为 /agents 岗位、hooks 自动化、/rewind 检查点。
**落地**：写飞叔版「用 Hermes 半年才摸出的 N 个命令」——真实使用痕迹背书，比文档搬运多一层信任。

## 3. 手机遥控升级了：三个教程不会主动告诉你的事（念灯 09-02）
**爆款要素**：「教程不会告诉你」=信息差选题；逆向角度：所有人吹新功能，他写暗面（会话转录上服务器、4个环境变量静默失效、企业开关默认关）；门槛做成速查表。
**可复用**：① 新功能发布次日写「但有三件事」，蹭热度+差异化一步到位；② 把官方文档「藏在中间的小字」挑成清单；③ 结尾给单一行动指令（如先开推送通知）。
**落地**：20年IT老手的判断力最适合这种「泼冷水评测」，立「只说真话」人设。

## 5. 公众号涨粉慢获客贵？20个亲测有效方法（老K的数字增长笔记 09-02）
**爆款要素**：开头失败案例（3万投流涨1217粉、单客4000元）立可信度；「按获客成本从低到高排」的编排逻辑；每方法带三数字：动作→月涨N粉→转化率。
**可复用**：① 案例必须有投入/产出/单位成本三个数；② 方法按成本排序不平铺；③ 合集文收藏率高，收藏=涨粉前置动作。
**落地**：套写《从400到1000粉，我亲测的N个动作》，按0成本内容动作→互推→付费排序，每条附自己后台截图。
