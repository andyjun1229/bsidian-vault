# 甲木：Hypit——Agent 自己复刻爆款视频的开源框架（文章要点 + 本机实操记录）

## 一句话

Hypit（github.com/hypit-ai/hypit，9月7日开源，Apache-2.0）：给它一条爆款视频，Agent 自己拆出结构；换内容/主播/语言，批量出片。视频写成代码（.svml 文件），改文本就是改视频。

## 核心机制：.svml = 视频版 HTML

- 一份 .svml 五层结构：Script（台词/角色）、Media Track（画面）、Caption（字幕）、Speech Track（语音合成）、Film（合成渲染）
- **关键设计：万物绑定台词而非时间轴**——删台词，语音/字幕/动画三样自动移除；改一句台词整条视频自动调
- segment 结构：01/06 编号，一段台词=一个片段
- .svml 是结构化文本 → Agent 最擅长读写，不用抽帧/转字幕/视觉识别绕圈

## 甲木的实测

素材：Tutti·VM 多Agent协作文章 → 三种风格三条 42 秒视频（6 片段）：
1. **MG 动画体**（米黄底+动画字幕，小红书科普风）
2. **网页排版体**（结构化排版+真人小窗+自动流程图）
3. **杂志体**（色块拼版，调性最强，甲木最爱）
配置：CLI + Kimi K3 多模态调度

### plan 拆出的 29 个请求（成本预估基础）

- gpt-image-2 生成：9 张 B-roll 图（2K，各不同比例）+ 1 张 presenter 主播图
- seedance-2-mini：2 段 720p 9:16 10秒带音频口播片段
- fishaudio-speech：1 次声音设计
- whisperx：2 次逐词对齐
- media-pipeline：渲染/混流/归一化/检查若干
- README 标注该示例总成本 **$1.15**

### 未完成的（需要账号/付费授权）

- `hypit build` 需要先 `hypit runtime init` 配置 Runtime Profile + 连接 HypiHub 账号或自有 Provider API key
- 免费路径存在：字幕/动效/代码渲染不调生成模型也能出片（$0 成片），但爆款复刻的 A-roll 口播需要 Seedance/GPT-Image 等付费模型

## 核心洞察

- 模板工具降操作门槛（出片但千篇一律）；Hypit 降**结构复制门槛**（好视频的结构拿过来换内容）
- 框架不动，模型升一代质量自动涨
- 开源可本地部署；工作流：每篇文章发完顺手出一条视频
