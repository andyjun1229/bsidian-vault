## 卡 1.《关于AI写作、公众号的那些坑，2.8万字，81个问题，全在这儿了》（阿水的ai写作之路 2026-09-15）
📌 微信找原文：搜一搜「关于AI写作、公众号的那些坑，2.8万字，81个问题，全在这儿了」→ 公众号「阿水的ai写作之路」+ 日期 2026-09-15

**爆款要素**：
- 标题三连数字（2.8万字 / 81个问题 / 全在这儿）：体量承诺 + 收藏价值可视化，「全」字封死读者「还需要再找」的念头；
- 蹭热搜的反噬红利：「夫妻靠AI写公众号年入200万」热搜是入口，本文卖的是「避坑」，热点第二波永远比第一波好写；
- 摘要直击 AI 文鉴伪特征：「没有人写作时突然的短句和突然的长句；结构太工整，起承转合像……」——用具体文本细节立专业人设；
- 长文即壁垒：2.8 万字本身就是传播点，转发理由是「存着总有用」。

**可复用**：
- 「热点翻车第二波」写法：热点爆发→第一波追事件→第二波写「避坑/复盘/清单」，竞争小、生命周期长；
- AI 文鉴伪三件套（句子节奏均匀 / 结构过于工整 / 无个人语癖）可做成自查清单，每发一篇对照一遍；
- 把自己踩过的坑累积成 FAQ 库，攒够 50 条就是一篇爆款底稿。

**适用性**：极高。飞叔 20 年写作 + 全程 AI 协作产稿，正好处在「既懂写作又懂 AI」的交叉点；此文结构可直接搬：《用 AI 写了 N 篇公众号之后，我踩过的 21 个坑》。

## 卡 2.《读完 Claude Code 的系统提示词, 我学到 7 件事》（Silent Talkie 2026-09-15）
📌 微信找原文：搜一搜「读完 Claude Code 的系统提示词, 我学到 7 件事」→ 公众号「Silent Talkie」+ 日期 2026-09-15
📎 一手公开信源（非微信，已验证）：HN 讨论 "We removed over 80% of Claude Code's system prompt for Opus 5 and Fable 5"（2026-07-25）https://twitter.com/trq212/status/2080710971228918066 ；抓包方法为 MITM，正文标题所提「6,621 行」即本波泄露版系统提示词

**爆款要素**：
- 信息差套信息差：第一层「系统提示词被扒出来了」，第二层「作者是用中间人抓包扒的」——方法本身的生猛感是二次传播点；
- 「6,621 行」荒诞具体数字进摘要，比「很长」可信百倍；
- 「学到 7 件事」：把吃透长文压缩成清单，读者 3 分钟白嫖作者 3 小时；
- 反差内核：人人以为提示词是玄学，读完发现全是工程常识——认知修正型内容自带转发理由。

**可复用**：
- 「读完 X 的 Y，我学到 N 件事」公式：任何一手长材料（官方文档/开源仓库/泄露文件）都能套；
- 编译向标准动作：一手信源 + 方法细节（怎么拿到的）+ 清单化压缩，三件齐了就是高质量二创；
- 顺手自查：自己的 Claude Code 一开机就吃掉几万 token，其中系统提示占大头——「给你的 CLAUDE.md 减负」是天然的续作选题。

**适用性**：高。飞叔天天用 Claude Code，写「我也去数了数自己的提示词」有实操背书；注意重点放在「对写作/知识库工作流的启发」而非纯技术复述。

## 卡 3.《一半的 AI 一人公司，月收入不到 7000 块——可他们里 95% 是本科以上，58% 已经干了 8 年以上》（头雁一姐 2026-09-15）
📌 微信找原文：搜一搜「一半的 AI 一人公司，月收入不到 7000 块」→ 公众号「头雁一姐」+ 日期 2026-09-15

**爆款要素**：
- 标题数字对撞的教科书：一半月入不足 7000（泼冷水）×95% 本科、58% 干了 8 年以上（泼第二盆）——两句话打碎「AI 轻松躺赚」幻想；
- 高学历 × 高年资 × 低收入的错位感制造认知失调：读者第一反应是「为什么」，点进去找答案；
- 调查数据体裁在吹风口文海里是降维打击：全网在讲「一个人活成一家公司」，这篇讲「大多数人的真实工资条」；
- 目标人群双向通吃：想入场的人看到风险提示，已入场的人看到自己被看见。

**可复用**：
- 「数据泼冷水」结构：现状数据（一半不到 7000）→ 人群画像反差（95% 本科/58% 八年）→ 原因分析 → 什么样的人还能做；
- 数字必须具体到「反常识」才有传播力：7000、95%、8 年，每个数都在打破一个默认想象；
- 公众号赛道同款题：《一半的公众号死在前 100 天——可坚持下来的人里，大多数阅读量也不过百》，用自己后台真实数据写。

**适用性**：极高。与飞叔「400 粉真实数据流」路线完全同频：不吹不黑、晒真实数字，恰好是 400→1000 阶段最能积累信任的内容资产。

## 卡 4.《他把写公众号的经验打包成AI Skill，99.9元涨价到599，卖出6万》（OPC百科 2026-09-15）

**爆款要素**：
- 摘要金句钉死全文：「AI 这波机会，到最后真正赚到钱的人，不是最懂技术的人，而是最会把 AI 拿去卖的人」；
- 标题三级跳数字：99.9 → 599 → 卖出 6 万，涨价曲线本身就是故事，暗埋「会卖的人早入场」的焦虑；
- 「写公众号的经验」×「AI Skill」= 把无形经验打包成可售价资产的完整路径，人人读完会代入「我的经验值多少钱」；
- 案例文自带争议：定价 599 的公众号写作课值不值，评论区必吵，吵就是热度。

**可复用**：
- 「经验资产化」叙事框架：你会什么（20 年 IT）→ 打包成什么（Skill/模板/清单）→ 卖给谁 → 定价逻辑；
- 涨价数字曲线标题可直接套：免费 → 9.9 → 99 的三段式比单一定价有故事性；
- 争议收口法：不复述案例，落一句自己的判断（知识付费的定价锚点是什么），把流量转成立场粉。

**适用性**：中高。飞叔暂不卖课，但「把 vault 工作流打包成可复用资产」正是既定方向；此文的定价叙事可直接用于写《我的 20 年 IT 经验，值多少钱一篇》做用户调研式试探。
