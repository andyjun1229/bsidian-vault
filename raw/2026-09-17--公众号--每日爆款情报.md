## 卡 1.《Claude Code 互联 Obsidian，搭一个自生长的知识库》（良哥运营笔记 2026-09-16 21:00）
📌 微信找原文：搜一搜「Claude Code 互联 Obsidian，搭一个自生长的知识库」→ 公众号「良哥运营笔记」+ 日期 2026-09-16

**爆款要素**：
- 摘要金句自带哲学味：「记笔记不是目的，让笔记下次自己冒出来才是」——把工具文拔高到知识管理观，命中知识工作者身份认同；
- 「自生长」一词是全文题眼：区别于市面泛滥的「搭建教程」，暗示系统是活的、会复利，制造「我还停在手动整理」的落后焦虑；
- 场景极简（Claude Code + Obsidian，两件人人都有的工具），门槛低 → 受众宽 → 「我也搭一个」的冲动转发。

**可复用**：
- 「工具组合 + 反常识动词」命名法：不说「教你搭建」，说「让它自己长」——动词决定文章气质；
- 写自己的真实系统截图 > 通用教程：飞叔的 vault 本身就是 raw→you→outputs 三级流水线，天然是「自生长知识库」的一手案例；
- 同赛道赛道密集度是信号：一周内多篇同题 = 平台推流偏好，此时入场吃的是话题红利。

**适用性**：极高。飞叔的 vault + Claude Code 工作流就是这个选题的真人实测版，别人写教程、他写「我的知识库已经开始自己长出下一篇文章了」，直接服务 400→1000 涨粉目标。

📌 微信找原文：搜一搜「Claude Code 之父放话：买最贵的AI，把Token烧穿」→ 公众号「AI学知社」+ 日期 2026-09-16
📎 一手公开信源（非微信，已验证）：Boris Cherny 是 Claude Code 创造者，HN 有其持续访谈记录（如 2026-07-27 访谈 https://www.youtube.com/watch?v=qyPCVqFUyDo 、How Boris Uses Claude Code https://howborisusesclaudecode.com ）；「只买最贵的模型」言论为其公开访谈观点，中文圈 9/10 起已有多篇转译（灵枢空间 9/10《8 个月不写一行代码》同源），9/16 此篇是发酵后的爆款版本。

**爆款要素**：
- 标题三件套：权威人设（Claude Code 之父）× 争议动作（烧穿）× 荒诞数字对撞（省 50% vs 赚十万倍），把一个访谈观点压缩成认知炸弹；
- 「烧钱」戳中所有 AI 付费用户的钱包神经，是 token 焦虑的镜像表达——上周全网教我省，这周教我烧，情绪反差自带传播势能；
- 名人金句文是编译向最低成本爆款：一手访谈 → 中文转译 → 金句标题，24 小时内可完成。

**可复用**：
- 「权威反常识」公式：〔领域大神〕放话〔违背读者当前做法的观点〕，正文用其原话+场景案例撑住；
- 与 9/16 情报卡 5（token 账单体）组成正反连续剧：「省钱派 vs 烧钱派」是现成的对比文结构；
- 编译文时效窗口 48 小时：遇到好的英文访谈，先出金句短评占位，再出深拆长文。

**适用性**：高。飞叔作为真金白银的 Claude Code 付费用户，写《我听了 Claude Code 之父的话，把订阅升到最高档，然后算了一笔账》既有立场又有一手数据，天然带争议互动。

## 卡 3.《一人剧组：一个人用 AI 做短剧，播放量过亿》（普通人攻略局 2026-09-16 00:01）
📌 微信找原文：搜一搜「一人剧组：一个人用AI做短剧，播放量过亿」→ 公众号「普通人攻略局」+ 日期 2026-09-16

**爆款要素**：
- 标题「一人 × 过亿」极限对撞：最小人力配置 × 最大流量结果，中间全是读者的好奇心缺口；
- 「一人剧组」是现成的身份标签词，读者可以自我代入（一个人 + AI = 一支队伍），比干巴巴的「AI 工具介绍」转发率高得多；
- 正文有清醒钩子：「'一人剧组'不是躺赚」——先给梦再泼水，避免了纯风口文的廉价感，攒信任。

**爆款要素**（补充）：
- 案例人物具体（美术出身、电商转行），有转型前后的路径细节，素人案例比大厂案例更有代入感。

**可复用**：
- 「身份标签词」提炼法：给一类人起名字（一人剧组/一人公司/超级个体），命名者占传播先机；
- 「先给梦再泼水」两段式：案例高潮 → 共同点拆解（普通人攻略局拆了三条共同点）→ 「你能复制哪部分」，比单向吹或单向黑都高级；
- 同款结构迁移：AI 短剧之于视频，正如 AI 写作之于公众号——飞叔可写「一人编辑部：我用 AI 跑通一个人的杂志」。

**适用性**：中高。飞叔不做视频，但「最小人力 × 最大产出」的叙事与他的「AI 一人公司」定位完全同构；可借案例写观点文，不必亲自做短剧。

## 卡 4.《做一人公司，第一步不是买 AI，而是先把这条线跑通》（ethan48岁重启 2026-09-16 20:50）
📌 微信找原文：搜一搜「做一人公司，第一步不是买AI，而是先把这条线跑通」→ 公众号「ethan48岁重启」+ 日期 2026-09-16

今日「一人公司」同题文至少 4 篇，此文用反常识角度在同题红海里杀出：标题虽然否定式，正文落点极稳——第一步不是买 AI，而是先把「谁给你付钱」这条线跑通。

**爆款要素**：
- 「不是 A，而是 B」否定式标题：直接推翻读者默认动作（看到 AI 风口→先买工具），用一句话完成认知纠偏；
- 扎心一问做记忆点：「到底谁会给这家公司付钱？」——所有看着风口热血上头的人被这一句拦腰截住；
- 同题红海差异化：同一天至少 4 篇「一人公司」文，吹风口的同质化，反常识泼冷水的稀缺。

**可复用**：
- 「不是 A，而是 B」句式是最省力的差异化武器：所有人写「怎么用 AI」时，写「先别用」；所有人吹「一人公司」时，写「先回答谁付钱」；
- 泼冷水文的信任红利：风口文涨阅读，冷水文涨粉丝（信你的人才关注），400→1000 阶段后者更值钱；
- 一天多篇同题 = 选题过热预警：此时入场必须带独特角度，纯跟风必沉。

**适用性**：极高。飞叔的「400 粉真实数据流」本来就是泼冷水路线的天然载体——《我想靠公众号赚钱，先回答谁给我付钱》直接套用，用自己后台数字说话。

- 场景具体到装备名（Claude Code + Trae + Stata MCP、平行趋势图配色、安慰剂检验 500 次迭代）——细节密度决定可信度，行话黑话是圈层暗号；
- 「你不是个例」的共情切入：从「同学三天跑完实证，我调了两天配色」的真实场景切入，先共情再卖课（AI Agent 全流程配置服务）。

**可复用**：
- 「代差句式」：〔你的同行〕已经在用〔工具组合〕跑通〔完整成果〕了，而你还在〔低效细节〕——任何垂直圈层通用；
- 圈层黑话密度=可信度：写公众号圈就晒后台截图、推荐位、看一看推流；写 IT 圈就晒 token 账单、prompt；

**适用性**：高。此文的圈层打法正是公众号打法——飞叔的垂直圈是「20 年 IT 老兵 × AI 工作流」，同样的结构可写《你的同行已经在用 Claude Code 写完 30 篇公众号了，而你还在手动排版》。
