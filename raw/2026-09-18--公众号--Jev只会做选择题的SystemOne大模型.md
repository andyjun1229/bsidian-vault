# Jev：只会做选择题的 System One 大模型

## 核心事实

- **产品**：Jev，TypeSafe AI 出品。创始人 Diogo Almeida，前 OpenAI，RLHF 和 InstructGPT 参与者，2024 年初离职创业
- **定位**：只做高频决策的通用分类器——不能聊天、不能写代码、不生成文字，只输出判断（Yes/No、A/B、继续/停止）
- **性能**：平均 380 毫秒完成一次判断（比传统 LLM 快 20~200 倍）；0.042 美元/百万 Token，输出 Token 免费（成本降 40~400 倍）；打游戏一秒决策 10 次
- **理论命名**：System One Model，出自卡尼曼《思考，快与慢》——现有 GPT/Claude/reasoning 模型都是系统2（慢思考），Jev 押注系统1（快思考）：世界上存在海量不需要长篇推理的智能任务

## 关键技术点：RLCD

Reinforcement Learning for Calibrated Decisions（面向校准决策的强化学习）。与 RLHF（优化人类偏好）、RLVR（优化可验证性，催生数学/代码跃进）并列的第三条训练路线：优化「决定对不对」+「模型说的置信度是否真实」。

**置信度分流机制（校准是核心，不只是快）**：
- 置信度 > 0.90 → 自动执行
- 0.7 ~ 0.90 → 交给更强的大模型复核
- < 0.7 → 交给人决策

**并行判断**：一条输入可同时问十个问题（是不是广告？是不是融资？值不值得推？）一次出结果——与 LLM 逐 Token 生成是两种思路。

## 应用案例

- Marcel Pociot 的浏览器插件：过滤 X 上不想看的内容（引战帖/加密货币/政治争吵），380ms 折叠一条
- 玩马里奥（按键判断）、操控浏览器查航班（7 秒点完全部）、交易机器人（买/卖判断）
- 作者（卡兹克）实测 AIHOT 预筛：100 道测试题对比——GLM-5.3 Flash 唯一全对但最慢最贵；Jev 准确第二+便宜很多，**并行判断场景下准确率最高、速度最快、成本第二低**；Qwen 3.7 Flash 最便宜但准确率差 7 个点

## 名字的含义：杰文斯悖论

19 世纪蒸汽机效率提高 → 用煤更划算 → 使用面扩大 → **社会总煤耗反而暴涨**。效率提升、单次消耗下降、总消耗暴涨。

TypeSafe 的赌注：智能也会发生杰文斯悖论——当一次有语义理解能力的判断便宜到接近免费，判断的使用量将暴涨。「AI 为什么一定要生成东西？智能当然可以用来创造，也可以只用来判断。」
