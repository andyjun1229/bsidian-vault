## 卡 1.《为了公众号涨粉，写作之前我给自己定下三条铁律》（哥论步写作 2026-09-19）
📌 微信找原文：搜一搜「为了公众号涨粉，写作之前我给自己定下三条铁律」→ 公众号「哥论步写作」+ 日期 2026-09-19

**爆款要素**：
- 「铁律」+「不遵守就别动笔」强承诺标题：把方法论包装成纪律，暗示文内有可执行 checklist，比「3 个技巧」高一个层级；
- 痛感比喻精确：「像在 KTV 里深情演唱，台下一个人都没有」——自嘲式共情，一句话完成读者筛选；
- 「有价值」被拆成三问过滤器（能了解什么 / 能解决什么 / 会不会转发）：口号变判据，可操作感强；
- 标题案例拆解到字词级（《无期徒刑可能不会坐一辈子牢，但这四个字会》的双层钩子：破认知+悬念）；
- 给出数字+故事叠加的成品模板（《从0粉丝到月入过万，我做公众号的第183天…3个真相》三要素同框）；
- 结尾升维：写作→数据→复盘→交流的成长闭环，把涨粉文拔到成长叙事，避免掉进算法鸡汤。

**可复用**：
- 三问过滤器直接当发文前 checklist；
- 「N 条铁律」标题框：经验清单升格为纪律，天然带执行暗示；
- 数字+故事+悬念三层叠加公式：183 天是数字、0 到月入过万是故事、3 个真相是悬念。

**适用性**：高。直接拿来当标题自查工具；更妙的用法是差异化改写——用 20 年 IT 的 code review 思维重写「三问过滤器」：先立验收标准再动笔（如同先写测试再写代码），成文《写作之前，我先给自己的文章做 code review》。

## 卡 2.《普通人做AI副业，别想着做平台，先做服务》（盛年AI笔记 2026-09-20）
📌 微信找原文：搜一搜「普通人做AI副业，别想着做平台，先做服务」→ 公众号「盛年AI笔记」+ 日期 2026-09-20

**爆款要素**：
- 「别想 A，先做 B」否定句式标题，直接砍掉读者第一反应（做平台/做工具站），反直觉但立刻给论证；
- 账目级自证：127 天、32 单、到手 7233.5 元——精确到小数点的数字比「月入过万」可信十倍，这是当下副业文的信任货币；
- 同价不同命对比讲透知识点：60 块 57 分钟交付 vs 70 块 21 天改 9 版，差异只在开工前问了 4 个问题；
- 第三方案例补全论证：技术很 low 的 AI 工具聚合包，卖传统行业小老板 2000 元/套×1000+ 客户——「服务长成产品的样子」；
- 文末钩子直给：回复「接单」领 32 单接单 SOP——把方法论直接转化成关注理由。

**可复用**：
- 「别想 A，先做 B」标题公式；
- 账目级数字（N 天 N 单 N.N 元）替代一切模糊成果表述；
- 同价对比案例结构：两单价格近似、过程迥异，差异点即知识点；
- 资料钩子：把文中方法整理成一页 SOP 做关注诱饵。

**适用性**：极高。飞叔的每日情报 Cron + vault 流水线本质就是「把服务沉淀成 SOP」的公众号版。可写《我不追爆款，我做交付》——把每篇情报的产出流程拆成可复用 SOP 送读者换关注。注意与 9/17 卡「先跑通付钱闭环」是同族演进，引用时标明关系避免自我重复。

## 卡 3.《从0到1：普通人的AI副业完整路径》（天玑AI日记 2026-09-11）
📌 微信找原文：搜一搜「从0到1：普通人的AI副业完整路径」→ 公众号「天玑AI日记」+ 日期 2026-09-11

**爆款要素**：
- 负面筛选开场：「这份指南不适合程序员、全职自媒体人、已月入过万者」——排除法让目标读者（上班族/宝妈）自我认定更强，被排除者反而好奇点入；
- 身份副标题三重可信：31 岁 + 产品经理 + 实战总结；
- 双层结构：先「3 个真相」纠偏认知，再「4 个阶段」给路径——先破后立的标准干货骨架；
- 阶段全部配时间盒（1-2 周/1 周/2-4 周/持续）：把焦虑变成日程表，这是「路径文」和「鸡汤文」的分水岭；
- 方向对比表（门槛星级×推荐星级）+ ❌避坑清单：两大收藏率利器同框；
- 里程碑定义精确：「赚到第一块钱。不是第一万块」——最小可验证成果思维。

**可复用**：
- 负面筛选开场：先说不适合谁，目标读者代入更快；
- 时间盒路线图：一切「从0到1」话题可套，以周为单位；
- 星级对比表：工具/方向盘点的标配呈现形式；
- 「第一块钱」式里程碑命名：把大目标切成可验证最小成果。

**适用性**：高。飞叔的 400→1000 粉本身就是「从0到1」叙事变体，可写《从400到1000粉的4个阶段》：每周一个小里程碑（如 Week1 标题验收制、Week2 合集串联、Week3 钩子话术、Week4 复盘调向），用产品经理式表格呈现，与「20 年 IT 老兵」人设无缝咬合。

## 卡 4.《公众号千粉瓶颈：每天拼命互动，没收益，你会不会想放弃？》（丽丽缘 2026-09-19）
📌 微信找原文：搜一搜「公众号千粉瓶颈：每天拼命互动，没收益，你会不会想放弃」→ 公众号「丽丽缘」+ 日期 2026-09-19

**爆款要素**：
- 超长口语化标题三连问（瓶颈/没收益/想放弃）：把目标读者此刻的内心 OS 原样做成标题，精准率极高；
- 两层不等式金句：「粉丝不等于阅读，阅读不等于完读」——一句讲清平台收益逻辑，可摘可转；
- 认知纠偏干货：平台判定收益看完读率、停留时长、有效点击，不看粉丝数——解释了「千粉账号不如几百精准粉小号」的反直觉现象；
- 对比金句：「精准的一百个完读粉，胜过一万个随手关注的路人粉」；
- 共情白描密度高：回评论回到手酸眼干、深夜自我怀疑——情绪陪伴拉完读；
- reframing 安慰式升级：「不是账号废了，是账号正在打磨标签、筛选人群」——把瓶颈重构成必经阶段。

**可复用**：
- 「A≠B，B≠C」不等式金句结构：任何反直觉认知都可压成这个句式；
- 读者内心 OS 直接做标题；
- 「精准 vs 路人」对比句式；
- 「不是失败了，是在筛选」式 reframing：安慰与认知升级一次完成。

**适用性**：极高，但需反转使用。丽丽缘的答案是「熬」，飞叔的差异化答案是「算」：老兵不该靠共情熬粥，该用数据思维给出可测量动作。成文《完读率才是400→1000的硬指标》，与 9/19「粉丝≠客户」接成「粉丝三不等式」系列：粉丝≠客户（商业）、粉丝≠完读（算法）、粉丝≠资产（复利）——一个金句结构撑起一个系列。
