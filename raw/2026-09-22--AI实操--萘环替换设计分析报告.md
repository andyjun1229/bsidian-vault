## 1. 第一步：从近30年FDA批准药物中锁定"萘环家族"

筛选逻辑：1996-2026 年间 FDA 批准的含萘环（naphthalene，两个稠合苯环）骨架的小分子药物。经 openFDA/PubChem 检索核验，代表性药物：

| 药物 | 靶点/适应症 | 批准（核验状态） | 萘环角色 |
|---|---|---|---|
| **萘普生 Naproxen** | COX抑制剂/NSAID | 1976处方（非近30年但作为萘环药物原型保留；OTC 1994） | 疏水锚 |
| **阿戈美拉汀 Agomelatine** | MT1/MT2激动剂/抑郁 | EMA 2009（美国未批） | 直接嵌入侧链 |
| **西那卡塞 Cinacalcet** | 钙敏感受体变构调节/甲旁亢 | FDA 2004 | 疏水片段 |
| **贝沙罗汀 Bexarotene** | RXR激动剂/皮肤T细胞淋巴瘤 | FDA 1999.12 | 双萘环核心 |
| **阿达帕林 Adapalene** | RAR选择性激动/痤疮 | FDA 1996 | 疏水萘环 |
| **他扎罗汀 Tazarotene** | RAR激动/银屑病 | FDA 1997 | 疏水萘环 |

**为什么选萘普生和阿戈美拉汀做设计原型**：两者萘环都是"疏水锚定基团"，分子量小（230/243）、合成可及性高、公开 SAR 资料丰富，是最适合演示萘环等排替换的两个骨架。维A酸类（阿达帕林/他扎罗汀/贝沙罗汀）萘环参与受体口袋更深相互作用，等排风险高，第一轮不碰。

**核验记录（诚实声明）**：
- 所有原型 SMILES 从 PubChem REST 拉取（2026-09-22）：萘普生 C14H14O3 MW230.26 ✓；阿戈美拉汀 C15H17NO2 MW243.30 ✓
- **纠错 1 例**：我最初凭记忆写的阿戈美拉汀结构（长酰胺侧链）与 PubChem 权威结构（N-乙酰基乙胺侧链，MW243）不符，已按权威源重建全部 AGO 系列设计——这正是流程图中"② 结构核验"步骤存在的意义
- openFDA drugsfda 的逐药批准日期查询当日受 API 限流未能全部完成，批准年份以 PubChem/PubMed 公开记载为准，精确到日的批准日期待网络窗口恢复后补核

## 2. 第二步：替换策略（6类生物等排体 + 1个破平面化设计）

萘环在药物化学中的经典替换策略及其逻辑：

| 替换体 | 等排逻辑 | 代表性先例药物（含该骨架的上市药） |
|---|---|---|
| 吲哚 | 等构体 + NH氢键给体 | 吲哚美辛、依托度酸（NSAID）；褪黑素本身是吲哚胺 |
| 苯并呋喃 | O原子降logP | 胺碘酮、达沙替尼 |
| 苯并噻吩 | S增强π极化、改代谢软点 | 雷洛昔芬、齐拉西酮 |
| 喹啉 | 环内N降logP提水溶性 | 氯喹、众多激酶抑制剂 |
| 吲唑 | 双N强偶极 | 阿昔替尼、帕唑帕尼 |
| 联苯 | 骨架简化、二面角可调 | 氯沙坦等沙坦类 |
| 2,3-二氢苯并呋喃 | sp3破平面（Fsp3↑） | 托特罗定含相关饱和稠环策略 |

### 3.3 四维定性推导（先例驱动，非实验结论）

**活性维度**：
- AGO-01（吲哚）是本系列理论最优——褪黑素本身就是 5-甲氧基吲哚胺，替换后分子回到内源配体的拓扑，MT1/MT2 识别口袋天然适配。这是"回到内源配体"策略。
- NPX-01（吲哚）有同系先例背书：依托度酸（etodolac，FDA 1991）就是吲哚骨架 NSAID，证明吲哚乙酸在 COX 口袋成药。

**选择性维度**：
- 喹啉/吲唑的环内 N 可作为氢键受体与口袋残基形成新的定向相互作用，是调节 COX-2/COX-1 或 MT1/MT2 选择性的经典把手。
- 联苯替换（NPX-06）通过二面角调节占据亚口袋，沙坦类先例证明该策略可精细调节选择性。

**代谢稳定性维度**：
- 萘环的 1,4 位是 CYP 氧化软点。苯并噻吩/苯并呋喃把氧化位点迁移到杂环邻位；吲唑替换后 logP 降 1.28（NPX-05，全组最大），肝摄取与氧化速率通常随之下降——文献中吲唑替换萘提升代谢稳定性的报道最密集。
- AGO-03（苯并噻吩）logP 反升 0.06，若目标是脑穿透（阿戈美拉汀本就是 CNS 药）反而是正向性质。

**毒性维度**：
- 平面稠合芳烃的共性风险：CYP 抑制、hERG。NPX-07/AGO-05（二氢苯并呋喃）把 Fsp3 从 0.21 提到 0.42+，打破平面性，是当前降平面毒性的主流设计语言。
- 吲哚 NH 引入新的氢键给体，可能带来脱靶（如 α2 肾上腺素受体）——AGO-02（苯并呋喃，等构无NH）正是 AGO-01 的风险备份方案。

## 4. 优先级建议（第一轮 wet-lab 前）

1. **AGO-01 吲哚**——"回内源拓扑"逻辑最硬，先做 MT1/MT2 结合 assay
2. **NPX-05 吲唑**——代谢稳定性收益最大（ΔlogP -1.28），先做肝微粒体稳定性对比萘普生
3. **NPX-07 二氢苯并呋喃**——破平面降毒，先做 CYP3A4 抑制 + hERG panel

验证顺序：结合/酶活 assay → 微粒体稳定性 → CYP/hERG panel → 细胞 → 动物。两项不过关即停，回第④步换骨架。

## 5. 诚实声明（重要）

1. **全部 12 个设计分子为 in-silico 提案，未经任何实验验证**。本报告所有"活性/选择性/代谢稳定性改善"的表述都是基于先例药物的定性推导和理化性质计算，不构成有效性结论。
2. 设计分子未查重商业专利数据库——**萘环等排替换在他汀/维A酸类专利中可能已被覆盖**，进入任何正式研发流程前必须做 FTO（自由实施）检索。
3. RDKit 的 cLogP 是计算值（Crippen 方法），与实验 logD 在离子化化合物（萘普生 pKa≈4.8）上会有显著偏差，湿验时请以实测为准。
4. openFDA 当日限流导致部分批准精确日期未核验，文档中批准年份为公开记载口径。
5. InChIKey 均为 RDKit 标准 InChI 生成，可直接在 PubChem 按 InChIKey 检索复核。
