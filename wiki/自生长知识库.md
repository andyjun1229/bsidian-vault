# 自生长知识库（Self-growing Knowledge Base）

**一句话定义：** 记笔记不是目的，让笔记下次自己冒出来才是——知识库是活的流水线（raw→you→outputs），会自己长出下一篇文章，而不是手动整理的仓库。

## 核心要点

- 题眼是「自生长」：区别于市面泛滥的「搭建教程」，暗示系统是活的、会复利，制造「我还停在手动整理」的落后焦虑（卡 1 爆款要素）
- 最小工具组合：Claude Code + Obsidian，两件人人都有的工具，门槛低→受众宽
- 一周内多篇同题 = 平台推流偏好信号，话题正在从「怎么装」进化到「怎么让它自己长」
- 护城河在真人实测：别人写通用教程，有真实系统的人写「我的知识库已经开始自己长出下一篇文章了」

## 关联概念

- [[wiki/贵模型论]] — 让知识库自生长的引擎是 Agent，Agent 的燃料是 token

## 与飞叔的关联

飞叔的 vault（raw→you→outputs 三级流水线）天然是这个选题的一手案例。情报卡给出明确选题路线：《我的知识库开始自己长文章了：raw→you→outputs 三级流水线实操》，全素材在 vault 里现成有，别人抄不走。
