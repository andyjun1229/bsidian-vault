# 贵模型论（Boris Cherny）

**一句话定义：** Claude Code 之父 Boris Cherny 的观点——买最贵的 AI，把 token 烧穿；省钱只能省 50%，赚钱能翻十万倍。

## 核心要点

- 与上周「token 刺客」账单文（省钱派）形成正反对撞：「全网教我省，这周教我烧」——情绪反差自带传播势能
- 底层逻辑：token 是燃料不是成本，模型的产出杠杆大于单价差；省 token 的天花板是 50%，用好模型的回报无上限
- 「权威反常识」公式：〔领域大神〕放话〔违背读者当前做法的观点〕，正文用原话+场景案例撑住
