# 给普通人的 AI 使用手册：场景-工具对照表

tags: [公众号]
---

今天参加公司内部的 AI 培训，坐了一个小时，下来什么感觉都没有。

不是讲得不好，是太对了。对到跟我没关系。

但转念一想，我写的 AI 文章，读者会不会也是这个感觉？

大部分人听到"Claude Code""OpenClaw""Hermes"这些词，脑子里只有一句话：这什么？

技术人觉得很简单的东西，对普通人来说，就像看到一个文件路径。

*明白了吧，不是他们不学，是你讲错了频道。*

你讲的是"这个工具很强"，他脑子里是"那我要不要学"。

你该讲的是"你想做这件事，用这个就行"。

---

## 我走过这个弯路

刚开始用 AI 的时候，我也在纠结：用什么工具？什么模型？什么框架？

后来发现，完全搞反了。

不是先选工具，是先看场景。

就像做菜，你是先想"今晚吃红烧肉"，再找锅和调料。不是先看到一口锅，再想"这锅能做什么"。

AI 也是这个道理。

---

## 我整理了一份场景-工具对照表

你可以按图索骥，找到适合你的组合。

---

## 一、写文档

### 场景 A：写公众号文章、博客、报告

**推荐：** ChatGPT + DeepSeek + 写作 skill

**流程：**
1. 你写初稿
2. 扔给 ChatGPT，让它帮你改结构、润色文字
3. 用 DeepSeek 检查是否有事实错误
4. 最后用写作 skill 统一风格

如果你有 OpenClaw（本地部署），可以配合 GLM 模型 + 写作 skill，一次性完成审稿编辑。

**为什么这样组合？**
- ChatGPT 文笔好
- DeepSeek 中文好，逻辑清晰
- 写作 skill 保证风格统一

---

### 场景 B：写学术文章、技术文档

**推荐：** Claude Code + 学术写作 skill + 学术搜索

**流程：**
1. 用 Claude Code 搜索相关文献
2. 让它帮你梳理结构
3. 生成流程图、架构图
4. 整理数据和统计图表

Claude Code 的 MCP 插件可以直接连接学术数据库，不用自己去找文献。

---

### 场景 C：快速写周报、邮件、通知

**推荐：** Kimi / DeepSeek / 通义千问

就选这 3 个中的一个即可，都够用。

你给个框架，让它帮你填内容。

**示例：**
> 帮我写周报，本周做了3件事：1. 完成项目A开发；2. 修复bug 5个；3. 参加产品评审会。

---

## 二、写提示词

### 场景 A：你知道要什么，只是表达不出来

**推荐：** 自己写，然后让 AI 帮你改

用 ChatGPT：
> 帮我优化这个提示词，让它更清晰、更具体：[你的提示词]

---

### 场景 B：你不知道要什么，只是模糊感觉

**推荐：** 直接问 AI

用 DeepSeek：
> 我想做[某件事]，但不知道具体怎么做，你能帮我理清楚吗？

---

### 场景 C：你想学写提示词

**推荐：** 看李继刚和花叔的提示词

他们写的确实厉害，有洞察，值得学。

但别只模仿，要学他们的思考方式。

---

## 三、画图

### 场景 A：为文章配图、做PPT

**推荐：** Midjourney / Stable Diffusion

如果你不会部署，用在线版的即可。

**提示词示例：**
> 一个温暖的办公场景，桌上有一杯藕粉和水果干，暖光，浅米色调，干净整洁

---

### 场景 B：画流程图、架构图、数据流向图

**推荐：** Mermaid / Draw.io

这两个是画图工具，不是 AI 生成。

但你可以用 AI 帮你写 Mermaid 代码：

用 ChatGPT：
> 帮我写一个 Mermaid 流程图，描述一个产品从需求到上线的流程

然后复制代码到 Mermaid，自动生成图。

---

### 场景 C：做产品设计、前端开发

**推荐：** IDE + 多模态模型 + MCP

这个需要技术背景，如果你不懂，跳过这个场景。

简单版：用 Figma 自带的 AI 功能，直接说"我想做个什么页面"，它帮你出设计稿。

---

## 四、程序开发

### 场景 A：写小程序、小工具

**推荐：** Claude Code + Opus

如果你没权限用 Claude Code，用 DeepSeek TUI + DeepSeek V4。

**操作：**
1. 打开你的 IDE
2. 输入"帮我做一个[功能]"
3. Claude Code 会帮你写代码、运行、调试

我这种人，不懂开发，也让 AI 帮我做出了一个数据管理平台。

如果你能说出具体需求，AI 能帮你把代码写出来。

---

### 场景 B：修复 bug、优化代码

**推荐：** Cursor / GitHub Copilot

这两个是 IDE 插件，安装到你的编辑器里，选中代码，右键"修复 bug"，它会帮你改。

---

## 五、创业 / 复杂项目

### 场景：从想法到产品，全流程用 AI

这个场景复杂一点，但能体现 AI 的真实能力。

---

#### 步骤 1：想法验证

用 ChatGPT：
> 我想做一个[产品/服务]，帮我分析一下可行性、目标用户、竞争对手

它会帮你做市场调研，找数据，给建议。

---

#### 步骤 2：产品设计

用 Claude Code：
> 帮我设计一个最小可行产品（MVP），包括功能清单、技术方案、开发计划

它会帮你梳理需求，画流程图，定技术栈。

---

#### 步骤 3：开发实现

用 Claude Code + Opus / DeepSeek TUI + DeepSeek V4

让它帮你写代码、画界面、搭数据库。

你不懂技术没关系，它会一步步教你。

---

#### 步骤 4：上线部署

用 Claude Code：
> 教我怎么把应用部署到服务器，包括域名、SSL证书、CDN配置

它会给你详细步骤，甚至会帮你写配置脚本。

---

#### 步骤 5：推广运营

用 ChatGPT：
> 帮我写一份推广方案，包括内容策略、渠道选择、KOL合作

它会帮你规划推广路径，给你可执行的清单。

---

这不是科幻。

我一个人，让 AI 帮我完成了一个数据管理平台，从想法到上线，前后一个月。

我这种人能做到，那些比我厉害的人，早就做出更牛的东西了吧。

---

## 关键不是学会工具

关键不是学会怎么用工具。

关键是知道：你要解决什么问题，然后用合适的工具组合去解决。

就像做菜，你不是要学会所有厨具。

你要知道今晚吃什么，然后找对锅和调料。

---

如果你想做这件事，就按我给的组合去试。

试了不行，再换。

别总问"AI 怎么用"，问"AI 能帮我做什么"。

门是开着，但你得先知道自己要去哪里。

*不是走进去，是想清楚为什么进去。*

就这样。
