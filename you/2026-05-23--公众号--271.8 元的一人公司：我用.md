最近一直在被"一人公司"种草。Anthropic 发布了官方版的一人公司手册后，我迫不及待想试一试。于是我让 AI 给我构建了一个"公司"，正好朋友最近也有一些需求，我正好用来试试这个 AI 军团的战斗力。

使用 Kimi Code 2.6 | 49元/月

公司的"眼睛和耳朵"，深入抖音、小红书、公众号、B站、知乎等主流平台，系统性搜集、归纳、分析信息，为公司提供决策依据。

核心能力：平台深度搜索、竞品分析、用户洞察、趋势追踪、情报归纳

使用 Kimi Code 2.6 | 与调研员共享

创意与策略并重，为客户品牌/产品制定专业的线上营销策划方案。既要有"big idea"的创意能力，也要有"可落地"的执行思维。

核心能力：品牌定位策划、营销活动策划、内容策略规划、推广策略设计、转化路径设计

使用 DeepSeek V4 Pro | 50元/月

连接"市场需求"和"技术实现"的关键桥梁。洞察用户需求，将模糊的想法转化为可落地的产品方案，并定义清晰的商业模式。

核心能力：需求洞察、产品设计、商业模式设计、PRD 撰写、竞品差异化

使用 DeepSeek V4 Pro | 与产品经理共享

公司视觉产出的核心。拥有双技能系统：huashu-design（设计排版）+libtv-skill（AI 生图/生视频）。

核心能力：营销海报、品牌VI、产品落地页、App原型、视频广告、产品渲染图

使用 DeepSeek V4 Pro | 与产品经理共享

公司的"建造者"。把产品经理的 PRD 变成可运行的产品，把设计师的视觉稿变成像素级还原的界面。

技术栈：React + TypeScript | Tailwind CSS | Next.js | PostgreSQL | Vercel

使用 GLM CODING PLAN | 172.8元/年

整个团队的大脑。理解每个角色的能力边界，在正确的时间把正确的任务交给正确的人，并确保最终产出质量。

核心职责：任务分解与分派、进度追踪、质量把关与决策、复盘与迭代、公司战略

需求调研员深入各平台搜集信息，输出结构化的调研报告

策划员工制定营销方案，产品经理定义产品形态和商业模式

设计师产出视觉素材，开发工程师实现产品功能

管理者协调资源、追踪进度、把控质量
