**六大原因分析：**
1. 🏭 「利好出尽」获利回吐 — 昨日 92 只涨停今日无法延续，AI 不是昨日主线
2. 💰 主力派发，散户接盘 — 寒武纪成交 199 亿、澜起 237 亿，放量下跌 = 资金出逃
3. 📉 创业板昨跌 4.37% 积蓄恐慌 — 高开只是虚假修复信号，为持有者提供逃顶窗口
4. 🤖 AI 板块高估值压力 — 龙头股 PE 极高，获利盘积压严重
5. 📰 外围/消息面可能偏空（网络受限未能获取最新新闻）
6. ⌚ 开盘 15 分钟即见顶，午后加速跳水，全天气氛极弱

**高开低走教科书级特征（经验总结）：**
开盘冲高 1-5% → 30 分钟内见顶 → 单边下行 → 午后加速 → 尾盘创新低。放量下跌、缩量反弹是最弱的信号。

## 事件二：DeepSeek 模型配置问题

**发现问题：** 配置文件设定了 `deepseek-v4-pro`，但实际会话跑在 kimi-k2.6 上。

**排查过程：**
1. 检查 `~/.hermes/config.yaml` → 配置正确写的是 deepseek
2. 系统提示显示 Model: kimi-k2.6, Provider: kimi-coding-cn
3. 子 Agent 测试 DeepSeek API → ✅ 正常工作（deepseek-v4-flash 和 deepseek-v4-pro 均可用）
4. 结论：当前会话被系统/会话级别覆盖了配置，需要结束会话重连才能生效

**解决方案：** 结束当前 kimi 会话 → 新开终端重新连接 → 新会话按配置走 deepseek-v4-pro。验证成功。
