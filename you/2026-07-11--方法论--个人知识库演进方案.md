# 个人知识库演进方案

> 基于文件索引 + 渐进式处理的知识库系统

**版本：** v1.0
**日期：** 2026-05-06
**目标：** 解决10年历史文件的整理难题，建立可持续的知识沉淀系统

tags: [方法论]
---

## 一、问题诊断

### 痛点1：原始知识存储

**场景：**
> 10年前存了一份重要报告，随意放在 Downloads 某个文件夹

**问题：**
> 现在想找，完全不记得在哪

**根源：**
- 文件分散在各个目录
- 没有统一的检索系统
- 没有元数据和标签

### 痛点2：历史数据迁移

**场景：**
> 10年的文件积累，如果要全部重新索引和处理

**问题：**
> 工作量巨大，不可能完成

**根源：**
- 传统方案要求移动文件
- 传统方案要求立即处理所有内容
- 传统方案没有优先级机制

---

## 二、核心设计原则

### 原则1：不移动原始文件

**理由：**
- 移动本身是巨大工作量
- 可能破坏原有的文件组织
- 增加用户心理负担

**策略：**
- 10年的文件就在原位置，不要动
- 只建立索引，不复制内容
- 通过索引定位，通过原路径访问

### 原则2：不立即处理所有文件

**理由：**
- 10年的数据不可能一次性消化
- 大量文件可能是低价值的
- 处理所有文件是资源浪费

**策略：**
- 采用渐进式处理
- 按需触发内容提炼
- 优先处理高价值文件

### 原则3：索引优先，处理其次

**理由：**
- 找到文件是第一步
- 知道文件在哪里就有价值
- 内容提炼可以慢慢来

**策略：**
- 先建立一个"统一索引"
- 让你能快速找到所有文件
- 内容提炼和知识转化，按需进行

#### 元数据提取（不做深度内容分析）

```python
def extract_metadata(filepath):
    """快速提取元数据"""
    try:
        # 1. 基本信息提取
        metadata = {
            'path': filepath,
            'size': os.path.getsize(filepath),
            'mtime': os.path.getmtime(filepath),
            'file_type': detect_file_type(filepath),
            'mime_type': detect_mime_type(filepath),
            'created_at': time.time(),
            'updated_at': time.time()
        }
        
        # 2. 快速内容预览（只读前500字符）
        if metadata['size'] < 100 * 1024 * 1024:  # 小于100MB才预览
            preview = extract_preview(filepath, max_chars=500)
            metadata['content_preview'] = preview
            
            # 3. 快速标题提取（如果可能）
            title = extract_title(filepath, preview)
            if title:
                metadata['title'] = title
        
        # 4. 初步重要性评分（基于时间、大小、访问历史）
        metadata['importance_score'] = quick_importance_score(metadata)
        
        # 5. 自动标签（基于路径、文件名）
        tags = generate_quick_tags(filepath)
        metadata['tags'] = tags
        
        # 6. 自动分类
        categories = quick_categorize(filepath)
        metadata['categories'] = categories
        
        return metadata
        
    except Exception as e:
        print(f"索引失败: {filepath}, 错误: {e}")
        return None
```

#### 快速重要性评分

```python
def quick_importance_score(metadata):
    """快速计算重要性评分（0-10）"""
    score = 0
    
    # 1. 文件大小（适中大小的文件更重要）
    size = metadata['size']
    if 10 * 1024 < size < 10 * 1024 * 1024:  # 10KB - 10MB
        score += 2.0
    elif size < 10 * 1024 * 1024:
        score += 1.0
    
    # 2. 文件类型
    file_type = metadata.get('file_type', 'other')
    type_scores = {
        'document': 2.0,
        'code': 1.5,
        'image': 0.5,
        'video': 0.3,
        'other': 0.1
    }
    score += type_scores.get(file_type, 0.1)
    
    # 3. 文件年龄（最近的文件更重要）
    days_old = (time.time() - metadata['mtime']) / 86400
    if days_old < 30:
        score += 1.0
    elif days_old < 365:
        score += 0.5
    
    # 4. 路径特征（某些路径的文件更重要）
    path = metadata['path']
    if '/Documents/' in path or '/Projects/' in path:
        score += 1.0
    elif '/Downloads/' in path:
        score -= 0.5  # Downloads 的文件通常临时性高
    
    # 5. 文件名特征（有意义的文件名）
    filename = os.path.basename(path)
    if any(kw in filename for kw in ['报告', '笔记', '方案', '文档']):
        score += 1.0
    elif filename.startswith('tmp') or filename.startswith('~'):
        score -= 1.0
    
    # 6. 归一化到 0-10
    score = max(0.0, min(10.0, score))
    
    return score
```

```python
def incremental_scan(since_timestamp):
    """增量扫描"""
    indexed_files = get_all_indexed_files()
    current_files = scan_directories()
    
    # 1. 新增文件
    new_files = [f for f in current_files if f not in indexed_files]
    for filepath in new_files:
        metadata = extract_metadata(filepath)
        add_to_index(filepath, metadata)
    
    # 2. 修改文件
    modified_files = []
    for filepath in indexed_files:
        if filepath in current_files:
            if os.path.getmtime(filepath) > since_timestamp:
                modified_files.append(filepath)
    
    for filepath in modified_files:
        # 更新元数据
        metadata = extract_metadata(filepath)
        update_index(filepath, metadata)
        
        # 如果已经提炼过内容，标记为需重新提炼
        if file_is_processed(filepath):
            mark_for_reprocess(filepath)
    
    # 3. 删除文件（软删除）
    deleted_files = [f for f in indexed_files if f not in current_files]
    for filepath in deleted_files:
        # 软删除，标记为已删除，保留历史记录
        mark_as_deleted(filepath)
    
    return {
        'new_files': len(new_files),
        'modified_files': len(modified_files),
        'deleted_files': len(deleted_files)
    }
```

```python
def generate_quick_tags(filepath):
    """基于路径和文件名生成自动标签"""
    tags = []
    
    # 1. 从路径提取
    path_parts = filepath.split('/')
    for part in path_parts:
        if part in ['Documents', 'Downloads', 'Projects', 'AI', '投资', '代码', '笔记']:
            tags.append(part)
    
    # 2. 从文件名提取
    filename = os.path.basename(filepath)
    keywords = ['报告', '笔记', '方案', '文档', '论文', '教程', '代码', '项目']
    for kw in keywords:
        if kw in filename:
            tags.append(kw)
    
    # 3. 从文件扩展名提取
    ext = os.path.splitext(filename)[1].lower()
    ext_tags = {
        '.md': 'Markdown',
        '.pdf': 'PDF',
        '.docx': 'Word',
        '.py': 'Python',
        '.js': 'JavaScript',
    }
    if ext in ext_tags:
        tags.append(ext_tags[ext])
    
    return tags
```

```python
def quick_categorize(filepath):
    """自动分类文件"""
    categories = []
    
    # 1. 基于路径
    if '/Documents/' in filepath:
        categories.append('文档')
    elif '/Projects/' in filepath:
        categories.append('项目')
    elif '/Downloads/' in filepath:
        categories.append('下载')
    elif '/Code/' in filepath:
        categories.append('代码')
    
    # 2. 基于文件类型
    file_type = detect_file_type(filepath)
    type_categories = {
        'document': '文档',
        'code': '代码',
        'image': '图片',
        'video': '视频'
    }
    if file_type in type_categories:
        categories.append(type_categories[file_type])
    
    # 3. 基于文件名关键词
    filename = os.path.basename(filepath)
    if 'AI' in filename or '人工智能' in filename:
        categories.append('AI')
    elif '投资' in filename or '股票' in filename:
        categories.append('投资')
    elif '健康' in filename or '养生' in filename:
        categories.append('健康')
    
    return list(set(categories))  # 去重
```

```python
def semantic_search(query_embedding, top_k=20):
    """语义搜索"""
    # 为高频文件预先计算 embedding（懒加载）
    # 低频文件在搜索时实时计算

    candidates = get_candidate_files_for_embedding(query_embedding, top_k=50)

    # 计算相似度
    results = []
    for file_id, embedding in candidates:
        similarity = cosine_similarity(query_embedding, embedding)
        results.append({
            'file_id': file_id,
            'similarity': similarity
        })

    # 排序并返回
    results.sort(key=lambda x: x['similarity'], reverse=True)
    return results[:top_k]
```

### 5.2 智能排序

**综合排序因子：**

```python
def calculate_search_score(file_info, search_query):
    """计算搜索分数"""
    score = 0

    # 1. 相关性（关键词匹配/语义相似度）
    score += file_info.get('relevance_score', 0) * 0.4

    # 2. 重要性评分
    score += file_info['importance_score'] * 0.3

    # 3. 访问频率
    if file_info['access_count'] > 0:
        score += min(file_info['access_count'] * 0.5, 2.0)

    # 4. 最近访问
    days_since_last_access = (time.time() - file_info['last_accessed']) / 86400
    score -= min(days_since_last_access * 0.1, 1.0)

    # 5. 时间新鲜度
    days_since_modified = (time.time() - file_info['mtime']) / 86400
    score -= min(days_since_modified * 0.05, 1.0)

    # 6. 处理状态
    if file_info['is_processed']:
        score += 1.0

    # 7. 用户标记
    if file_info['is_important']:
        score += 2.0

    return score
```

```python
    if file_info['is_processed']:
        return False

    # 2. 用户手动标记为重要的，处理
    if file_info['is_important']:
        return True

    # 3. 重要性评分高的，处理
    if file_info['importance_score'] >= 7.0:
        return True

    # 4. 文件类型为文档的，优先处理
    if file_info['file_type'] in ['document', 'code']:
        if file_info['importance_score'] >= 5.0:
            return True

    # 5. 文件大小适中的，考虑处理
    if 10 * 1024 < file_info['size'] < 10 * 1024 * 1024:
        if file_info['importance_score'] >= 6.0:
            return True

    # 6. 默认不处理
    return False
```

### 7.2 置信度评分机制

#### 评分模型

```python
class ConfidenceScorer:
    def __init__(self):
        self.authority_weights = {
            'peer_reviewed': 10,      # 同行评审论文
            'industry_report': 8,      # 行业报告
            'expert_opinion': 6,       # 专家观点
            'blog_post': 4,           # 博客文章
            'personal_note': 2,       # 个人笔记
            'casual_conversation': 1,  # 闲聊对话
        }

        self.decay_rates = {
            'core_theory': 0.01,       # 核心理论：衰减极慢
            'methodology': 0.05,       # 方法论：慢衰减
            'case_study': 0.10,        # 案例：中等衰减
            'temporal_note': 0.20,     # 临时笔记：快衰减
            'bug_record': 0.30,        # bug记录：极快衰减
        }

    def calculate_score(self, knowledge_item):
        """计算置信度分数"""
        # 1. 基础分（来源权威度）
        base_score = self.authority_weights.get(
            knowledge_item['source_type'],
            1
        )

        # 2. 佐证加分
        citation_bonus = min(
            knowledge_item['citation_count'] * 0.5,
            3.0  # 最多加3分
        )

        # 3. 时效衰减
        age_days = (datetime.now() - knowledge_item['created_date']).days
        decay_factor = self.decay_rates.get(
            knowledge_item['knowledge_type'],
            0.10
        )
        age_penalty = 1.0 / (1.0 + decay_factor * age_days / 30.0)

        # 4. 使用频率加分
        usage_bonus = min(
            knowledge_item['query_count'] * 0.2,
            2.0  # 最多加2分
        )

        # 5. 综合分数
        total_score = (base_score + citation_bonus + usage_bonus) * age_penalty

        return min(total_score, 10.0)  # 最高10分
```

#### 低分知识处理

- **置信度 < 3.0**：标记为"待审核"
- **置信度 < 2.0**：自动降级到情节记忆
- **置信度 < 1.0**：30天后自动删除

### 8.2 优先级队列

```python
def get_processing_queue(limit=10):
    """获取待处理队列（按优先级）"""

    sql = """
        SELECT id, path, importance_score, access_count, last_accessed
        FROM files
        WHERE deleted_at IS NULL
        AND is_processed = 0
        AND is_important = 0  -- 已标记为重要的已单独处理
        ORDER BY
            importance_score DESC,
            access_count DESC,
            last_accessed DESC
        LIMIT ?
    """
    return execute_query(sql, [limit])
```

**优先级排序：**
1. 重要性评分（importance_score）
2. 访问频率（access_count）
3. 最近访问（last_accessed）
