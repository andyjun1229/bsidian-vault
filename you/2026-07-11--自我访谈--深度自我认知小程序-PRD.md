# 深度自我认知系统 · 微信小程序产品方案

## 一、产品定位

**一句话：** 让AI像顶级访谈主持人一样，帮你拆解自己。

不是心理测试，不是MBTI替代品。是一个基于"名人访谈追问逻辑"的深度自我对话工具。

**核心差异：**
- 不是"给你一个标签"，是"帮你拆解你是怎么样一步一步变成现在这个人的"
- 不是"一次性测试"，是"可持续的自我探索过程"
- 不是"填问卷"，是"跟AI对话"

---

## 二、用户场景

| 场景 | 用户痛点 | 小程序怎么解决 |
|------|---------|---------------|
| 职业转型纠结 | 换不换？怕选错 | 帮你拆出是"真的不适合"还是"习惯遇难就逃" |
| 人际相处累 | 不知道为什么跟人处不好 | 追问链挖出你的信任模式和冲突盲点 |
| 测试做了没用 | MBTI/大五人格做了不知道下一步 | 给出可行动的分析，不是标签 |
| 重大决定前 | 不确定自己的判断是否客观 | 多角度追问逼你看到自己的偏见 |
| 想改变动不了 | 知道该改就是改不了 | 先找到"为什么改不了" |

## 三、核心功能

### 3.1 单人深度访谈（核心功能）

用户与AI进行结构化对话，每天7-8个问题，5-7天完成一轮。

**对话流程：**

```
用户打开小程序 → AI打招呼+建立信任 → 开始第一问
    → 用户回答 → AI根据回答追问1-3层
    → 用户再次回答 → AI记录并继续下一问
    → 每天结束时生成当天小结
    → 第二天AI从上次中断处继续
```

**关键设计点：**

| 设计项 | 做法 | 目的 |
|--------|------|------|
| 追问问答 | AI不跳转下一题，先追问 | 模拟杨澜/易立竞式深入 |
| 矛盾回溯 | AI发现前后矛盾时主动提问 | 模拟易立竞"矛盾摆上台面" |
| 沉默留白 | 用户长时间不输入，AI不催促 | 真实的访谈节奏 |
| 进度保存 | 随时退出，下次继续 | 适应碎片时间 |
| 每日7-8问 | 每题约3-5分钟，总时长可控 | 每天花20-30分钟即可 |

### 3.2 分析报告

完成全部39个问题后，AI生成一份结构化的分析报告：

- **核心画像：** 终极驱动力 / 核心矛盾 / 最大优势 / 最大盲点
- **维度分析：** 每个维度的独立拆解
- **交叉验证：** 维度间的矛盾点
- **发展建议：** 优势赛道 + 行动方向

### 3.3 历史记录

- 查看每一轮的对话记录
- 对比不同轮次的分析报告（人随时间变化）
- 回顾自己的回答，自我观察

## 四、页面结构

### 4.1 页面清单

| 页面 | 功能 | 备注 |
|------|------|------|
| 首页 | 品牌展示 + 开始入口 | 新用户引导页 |
| 个人信息页 | 姓名/年龄/职业等基础信息 | 首次必填，后续可修改 |
| 访谈页 | AI对话界面 | 核心交互页面 |
| 报告页 | 分析报告展示 | 完成全部问题后解锁 |
| 历史页 | 过往对话记录 + 报告回顾 | Tab页 |

### 4.2 页面导航

```
首页 → 个人信息页（首次） → 访谈页 → 报告页
                                         ↓
                                     历史页（Tab）
```

### 4.3 核心页面原型描述

**首页：**
- 品牌Logo + 名称"飞叔沉思录"或"DeepTalk Self"
- "开始深度访谈"按钮
- 已有进度的用户显示"继续上次访谈（第X/39题）"
- 已完成用户显示"查看我的分析报告"

**访谈页（核心）：**
- 顶部：进度条（X/39）
- 中部：AI对话气泡（类似微信聊天界面）
  - AI问 → 用户答 → AI追问 → 用户再答
- 底部：语音输入 + 文字输入
- 特色：AI的回答有节奏感，有时停顿，有时连续追问

**报告页：**
- 卡片式布局，可截图分享
- 核心发现放在最前面
- 支持PDF导出或保存到相册

## 五、技术方案

### 5.1 架构选择

```
[微信小程序前端] ←→ [微信云开发/云函数] ←→ [大模型API]
```

**推荐方案：微信云开发**

优势：
- 无需自建服务器
- 云函数天然对接微信登录（OPENID）
- 云数据库存用户数据
- 开发成本最低

### 5.2 AI能力来源

**方案A：接入大模型API（推荐）**

通过微信云函数调用大模型API（DeepSeek/通义千问）：

```
云函数接收用户回答 → 拼接提示词 → 调用API → 返回AI追问 → 展示给用户
```

提示词工程是本产品的核心技术壁垒——39个问题的追问链已经设计好，只需按要求格式嵌入提示词。

**优势：**
- 真正的AI对话体验，跟文章描述一致
- 追问自动智能化
- 报告自动生成

**成本估算：**
- 一次完整访谈≈3000-5000 token（输入）+ 2000-3000 token（输出）
- DeepSeek API成本≈0.5元/人/轮
- 假设1000用户/月 → 500元/月

**方案B：离线模式（备选）**

纯前端JS实现——预置所有问题和追问路径，用户选择答案后自动匹配下一问。

**优势：** 无需API费用，无网络也能用
**劣势：** 固定追问，没有AI的灵活性；报告质量受限

**建议：** 以方案A为主力，方案B作为"API不可用时的降级方案"

### 5.4 提示词架构（核心技术）

```
【系统提示词】
你是一位深度访谈主持人，借鉴杨澜、易立竞、许知远的访谈风格。
你的任务是按照5维度39题框架对用户进行深度访谈。

【规则】
1. 每次只问一个问题，等用户回答后再决定下一步
2. 用户回答后，先追问1-3层，再进入下一题
3. 发现矛盾时，温和地指出来
4. 不评判、不给出建议、不打标签
5. 每天7-8个问题

【当前状态】
当前轮次：第1轮
已完成：第5题/共39题
已记录的答案：[简要摘要前5题内容]

【下一个问题】
请提问第6题：XXX
```

## 九、开放问题

以下问题需要在开发前确认：

1. **AI API用哪个？** DeepSeek（已有key）还是通义千问？

2. **第一次使用是否要求用户注册？** 还是直接用微信登录（静默）？

3. **收费标准？** 免费 / 首次免费后续收费 / 完全免费引流到公众号变现？

4. **小程序名称？** DeepTalk Self / 飞叔对话 / 深度访谈 / 其他？

5. **是否需要"多轮对比"功能？** 让用户看到自己半年后的回答跟半年前有什么变化？
