# 数据中台实操模拟小程序 — 产品需求说明书

## 1. 产品概述

### 1.1 产品定位

一款面向**有数据开发基础**的从业者的**实操模拟**小程序。不是文档阅读器，不是视频播放器——而是一个能像真实阿里云控制台一样**点、配、跑**的交互式模拟环境。

### 1.2 目标用户

- 已有数据开发经验（SQL、ETL、基础数仓概念），想快速上手阿里云数据中台
- 正在面试/准备转岗，需要熟悉 DataWorks/DataHub/Flink 实际操作的从业者
- 公司正在上阿里云数据中台，需要团队快速熟悉实操的技术人员

### 1.3 核心价值

- **零成本实操**：不用买阿里云资源，不用开账号，打开小程序就能模拟
- **场景化学习**：基于真实业务场景（电商订单分析、实时大屏）组织学习路径
- **所见即所得**：界面风格贴近真实控制台，操作逻辑完全对应
- **离线可用**：所有模拟逻辑纯前端，不依赖网络环境

## 3. 功能详述

### 3.1 首页 — 学习路径 + 英雄之旅

#### 3.1.1 角色选择

用户首次进入时选择身份，影响推荐的学习路径：

| 角色 | 推荐路径 |
|------|---------|
| 数据开发工程师 | DataWorks 任务编排 → 数据治理 → Flink 实时计算 |
| 数据运维工程师 | DataWorks 运维监控 → DataHub 数据总线 → 报警配置 |
| 数仓工程师 | DataWorks 数据建模 → 数据集成 → 离线数仓实战 |
| 数据分析师 | DataWorks SQL查询 → 数据分析服务 → 数据API |
| 其他/自由探索 | 全部开放，按组件导航 |

#### 3.1.2 英雄之旅（闯关式学习路线）

三个组件各设计 5-8 个关卡，逐步深入：

**DataWorks 关卡**
```
L1: 创建第一个工作空间 → 理解项目隔离概念
L2: 配置第一个数据源（MySQL→MaxCompute）→ 理解数据源管理
L3: 编写SQL节点并运行 → 了解DataWorks IDE
L4: 搭建3节点DAG工作流 → 理解任务依赖
L5: 配置定时调度 → 了解调度周期/依赖
L6: 设置质量监控规则 → 理解数据质量
L7: 查看运维中心 → 理解任务实例/日志
L8: 完成一次数据集成任务 → 理解同步机制
```

**DataHub 关卡**
```
L1: 创建Project和Topic → 理解Topic类型（Tuple/Blob）
L2: 配置Shard数量 → 理解数据分片
L3: 通过Connector同步到MaxCompute → 理解数据归档
L4: 模拟数据写入和消费 → 理解发布/订阅
L5: 监控Shard负载 → 理解数据流量管理
```

**Flink 关卡**
```
L1: 创建项目空间 → 理解Flink部署模式
L2: 编写第一个Flink SQL作业 → 了解Flink SQL语法
L3: 配置数据源（DataHub → Flink）→ 理解Source
L4: 设置Sink到结果表 → 理解数据输出
L5: 启动并监控作业 → 理解Checkpoint/Savepoint
L6: 作业调优（并行度/资源配置）→ 理解性能调优
```

#### 3.1.3 进度追踪

- 每个关卡标记：🔒 未解锁 / 📖 学习中 / ✅ 已完成
- 线性解锁：完成上一关才能解锁下一关
- 累计完成进度条，提供成就感

### 4. DataWorks 模拟器（核心模块）

这是三个模拟器中最复杂的，也是用户最核心的需求。

#### 4.1 工作空间管理

**真实操作模拟：**

| 操作 | 模拟方式 | 界面要素 |
|------|---------|---------|
| 创建工作空间 | 表单填写，模拟创建动画+结果页 | 工作空间名称、模式选择（标准/简单）、计算引擎（MaxCompute/EMR/Hologres） |
| 查看工作空间列表 | 卡片/列表形式展示 | 名称、模式、状态（运行中/已停用）、创建时间 |
| 计算资源设置 | 模拟选择资源组 | 资源组类型（独占/公共）、规格（4CU/8CU/16CU） |
| 成员管理 | 模拟添加RAM用户 | 账号、角色（管理员/开发/运维/访客） |

**学习要点**：强调工作空间是 DataWorks 的隔离单元，不同环境（dev/test/prod）建议不同的 workspace。

#### 4.2 数据源管理

**模拟支持的数据源类型：**

- MySQL / PostgreSQL / SQL Server
- MaxCompute（ODPS）
- Hologres
- OSS
- DataHub（作为数据源接入）

**操作流：**
```
打开数据源列表 → 点击「新增数据源」 → 选择数据源类型
  → 填写连接信息（JDBC URL/Region等）→ 模拟「测试连通性」
  → 保存数据源 → 列表显示
```

**关键模拟**：「测试连通性」按钮点击 → 显示 loading → 返回「连通成功」或模拟常见错误（如超时、权限不足）。

#### 4.3 数据开发（代码编辑器）

**模拟 DataWorks 的 Web IDE 界面：**

- **SQL 节点**：语法高亮的 SQL 编辑器（mock），支持执行模拟
- **Shell 节点**：模拟运行 shell 脚本
- **MR 节点**：模拟 MapReduce 任务提交
- **数据同步节点**：模拟数据集成的配置界面

**SQL 节点模拟执行：**
```
用户编写 SQL（如 SELECT * FROM ods_order WHERE dt='${bizdate}'）
→ 点击「运行」→ 模拟运行动画 → 显示模拟结果（mock 数据表）
→ 或显示模拟错误（如语法错误、表不存在）
```

**内置模拟 SQL 场景**（10+ 个预置 SQL，覆盖常见 ETL 模式）：
- 全量同步：`INSERT OVERWRITE TABLE dwd_order PARTITION(dt) SELECT ...`  
- 增量同步：`INSERT INTO dws_daily_sales ... GROUP BY ...`
- 数据清洗：清洗空值、格式转换
- 维度关联：多表 JOIN 生成宽表

#### 4.4 工作流编排（DAG 模拟）

**这是最核心的模拟功能之一：**

- 模拟 DataWorks 业务流程（Business Flow）界面
- 提供虚拟节点拖放：SQL节点、Shell节点、数据同步节点、虚拟节点（开始/结束）
- 节点连线设置依赖关系

**DAG 编辑模式（简化版）：**

```
          ┌──────────┐
          │ 开始节点   │
          └────┬─────┘
               │
        ┌──────┴──────┐
        │             │
   ┌────▼────┐  ┌────▼────┐
   │ SQL:     │  │ SQL:     │
   │ ods→dwd  │  │ ods→dim  │
   └────┬────┘  └────┬────┘
        │             │
        └──────┬──────┘
               │
          ┌────▼────┐
          │ SQL:     │
          │ dwd→dws  │
          └────┬────┘
               │
          ┌────▼────┐
          │ Shell:   │
          │ 数据导出  │
          └─────────┘
```

**实现方式**：WXML 用 canvas 或 view 组合实现简化 DAG，节点可点击编辑。

#### 4.5 调度配置

**模拟 DataWorks 的调度设置：**

| 配置项 | 模拟选项 |
|--------|---------|
| 调度类型 | 周期性调度 / 手动触发 |
| 调度周期 | 分钟/小时/天/周/月 |
| 具体时间 | 每天凌晨 02:00、每周一 03:00 等 |
| 依赖属性 | 依赖上一周期、跨周期依赖 |
| 超时设置 | 超时时间（分钟） |
| 重跑属性 | 失败自动重跑、重跑次数 |

**模拟运行**：配置完成后，模拟展示「实例生成」过程 → 显示未来 N 个周期的实例列表 → 点击实例模拟查看运行日志。

#### 4.6 运维监控

**模拟 DataWorks 运维中心：**

- **实例列表**：展示任务实例，每个实例显示状态（等待/运行中/成功/失败）
- **DAG 视图**：展示实例级别的工作流 DAG，绿色=成功、红色=失败、黄色=运行中
- **操作日志**：模拟展示运行日志的关键片段
- **报警记录**：模拟失败报警通知

**关键模拟功能**：
- 点击实例 → 查看运行日志（mock 日志内容，包含真实格式）
- 失败实例 → 点击「重跑」→ 模拟重跑流程
- 实例依赖图 → 查看上下游依赖

### 5. DataHub 模拟器

#### 5.1 数据总线操作

**模拟 DataHub 控制台的核心功能：**

| 操作 | 模拟方式 |
|------|---------|
| 创建 Project | 填写 Project 名称、描述、Region |
| 创建 Topic | 选择类型（Tuple/Blob）、配置 Shard 数量、有效期 |
| Tuple Schema | 模拟添加字段（名称/类型/备注），支持强 Schema |
| Shard 管理 | 显示 Shard 列表、状态、起始/结束偏移量 |
| Connector 配置 | 创建同步任务（DataHub → MaxCompute/OSS） |

**Topic 类型对比模拟：**

| 维度 | Tuple Topic | Blob Topic |
|------|------------|------------|
| Schema | 强 Schema，需定义字段 | 无 Schema，纯二进制 |
| 使用场景 | 结构化流数据 | 非结构化数据（日志、图片） |
| 查询能力 | 可按字段过滤 | 按时间范围 |
| 示例 | 用户行为日志schema | 原始访问日志 |

**模拟交互流程：**
```
进入DataHub → 选择Project → Topic管理页面
→ 点击「创建Topic」→ 填写配置 → 点击确认
→ 返回Topic列表 → 看到新Topic
→ 点击Topic详情 → 查看Shard详情/连接信息/Connector
```

#### 5.2 数据写入/消费模拟

- **模拟数据生产**：点击「模拟写入」→ 选择速率（10条/s/100条/s/1000条/s）→ 显示实时写入动画
- **模拟数据消费**：点击「模拟消费」→ 展示消费记录列表（offset/timestamp/数据内容预览）

### 7. 实战场景（完整链路）

每个场景串联 DataWorks + DataHub + Flink 三个组件，模拟一个真实的数据中台项目。

#### 7.1 场景1：电商离线数仓

**业务背景**：某电商平台需要搭建离线数仓，完成 ODS → DWD → DWS → ADS 分层建设。

**涉及组件**：DataWorks（核心）+ DataHub（数据同步入仓）

**模拟任务流**：
```
1. DataWorks: 创建工作空间，配置 MySQL 数据源   [数据集成]
2. DataWorks: 创建数据同步任务 MySQL → ODS 层    [数据集成]
3. DataWorks: 编写 SQL 节点 ODS → DWD（清洗）    [数据开发]
4. DataWorks: 编写 SQL 节点 DWD → DWS（聚合）    [数据开发]
5. DataWorks: 编排工作流（DAG），设置依赖关系     [工作流编排]
6. DataWorks: 配置定时调度（每天凌晨 2 点）       [调度配置]
7. DataWorks: 查看运维中心实例运行情况             [运维监控]
8. DataWorks: 配置数据质量监控规则                 [数据质量]
```

**模拟产出**：最终 DWS 层聚合表数据（mock 显示）、调度实例列表、运行日志。

#### 7.2 场景2：实时订单大屏

**业务背景**：业务部门需要实时看到全国各区域的订单情况，刷新间隔 < 5 秒。

**涉及组件**：DataHub（数据采集 + 总线）+ Flink（实时计算）

**模拟任务流**：
```
1. DataHub: 创建 Project 和 Topic（Tuple 类型）   [数据总线]
2. DataHub: 定义 Schema（订单字段）               [Schema 配置]
3. DataHub: 模拟写入数据（100条/s）                [模拟数据生产]
4. Flink: 创建项目空间                             [空间管理]
5. Flink: 编写 SQL 作业（1分钟窗口聚合订单金额）    [SQL 开发]
6. Flink: 配置 Source = DataHub，Sink = 结果表     [连接器配置]
7. Flink: 部署并启动作业                            [作业管理]
8. Flink: 查看作业监控指标                          [作业监控]
```

**模拟产出**：实时计算结果表不断刷新、Flink 作业状态仪表盘。

#### 7.3 场景3：数据治理

**业务背景**：数仓上线后需要建立数据治理体系，包括数据质量、血缘、权限。

**涉及组件**：DataWorks（质量中心 + 数据地图）

**模拟任务流**：
```
1. DataWorks: 配置质量监控规则（表行数波动阈值）    [数据质量]
2. DataWorks: 模拟调度运行触发质量校验              [质量运行]
3. DataWorks: 查看数据血缘图                        [数据地图]
4. DataWorks: 配置表权限                           [数据安全]
5. DataWorks: 查看数据资产大盘                      [资产管理]
```

### 8. 知识库 / 速查手册

#### 8.1 概念速查

专门针对「有基础想快速掌握具体操作」的用户设计，不讲原理，只讲：

- **这个组件用来做什么**（一句话）

## 附录 A：预置模拟 SQL 模板

**数据开发节点 > SQL 节点 > 常用模板：**

```sql
-- 1. ODS → DWD：清洗空值
INSERT OVERWRITE TABLE dwd_order_detail PARTITION(dt='${bizdate}')
SELECT order_id, user_id, product_id,
       COALESCE(amount, 0) AS amount,
       COALESCE(pay_time, create_time) AS pay_time
FROM ods_order_detail
WHERE dt = '${bizdate}';

-- 2. DWD → DWS：日聚合
INSERT OVERWRITE TABLE dws_daily_sales PARTITION(dt='${bizdate}')
SELECT dt,
       COUNT(DISTINCT user_id) AS uv,
       COUNT(order_id) AS order_count,
       SUM(amount) AS total_amount,
       SUM(amount) / COUNT(order_id) AS avg_order_amount
FROM dwd_order_detail
WHERE dt = '${bizdate}'
GROUP BY dt;

-- 3. DWS → ADS：Top 10 热销商品
INSERT OVERWRITE TABLE ads_top_selling_products PARTITION(dt='${bizdate}')
SELECT product_id, product_name, SUM(quantity) AS total_qty
FROM dwd_order_detail
WHERE dt >= DATE_SUB('${bizdate}', 7)
GROUP BY product_id, product_name
ORDER BY total_qty DESC
LIMIT 10;
```

## 附录 B：预置 Flink SQL 模板

```sql
-- 1. 滚动窗口聚合（TUMBLE）
CREATE TEMPORARY TABLE orders (
  order_id VARCHAR, user_id VARCHAR, amount DOUBLE,
  order_time TIMESTAMP(3), WATERMARK FOR order_time AS order_time
) WITH ('connector' = 'datagen', 'rows-per-second' = '100');

CREATE TEMPORARY TABLE order_stats (
  window_start TIMESTAMP(3), total_amount DOUBLE, order_count BIGINT
) WITH ('connector' = 'print');

INSERT INTO order_stats
SELECT TUMBLE_START(order_time, INTERVAL '1' MINUTE),
       SUM(amount), COUNT(*)
FROM orders
GROUP BY TUMBLE(order_time, INTERVAL '1' MINUTE);

-- 2. 双流 JOIN（实时宽表）
INSERT INTO enriched_orders
SELECT o.order_id, o.user_id, u.user_name, o.amount, o.order_time
FROM orders o
JOIN users u ON o.user_id = u.user_id;
```
