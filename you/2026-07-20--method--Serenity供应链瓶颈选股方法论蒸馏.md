# Serenity 供应链瓶颈选股方法论（蒸馏版）

> **白毛股神 Serenity（@aleabitoreddit）** — Reddit/X 传奇投资者，其选股方法已被多人开源为 Agent Skill（GitHub 共 3500+ stars）。

## 一句话总结

**找大行情里的「霍尔木兹海峡」**：沿着产业链向上游追溯，找到那个"一旦断货、万亿产业就要地震"的关键节点——产能扩不出来、短期内替代不了的环节。那个节点上的公司（尤其是小盘股）拥有定价权，涨幅弹性最大。

---

## 核心逻辑

```
① 大行情爆发（AI/机器人/新能源等）
    ↓
② 上游需求暴增，某些关键环节产能跟不上
    ↓
③ 瓶颈环节掌握定价权 → 其中小盘股弹性最大
```

**类比：** 霍尔木兹海峡是全球石油的咽喉。一旦封锁，所有人都受影响。但如果你在霍尔木兹海峡拥有股份，你就拥有了定价权。哪个环节是某个大赛道的"霍尔木兹"？哪家公司控制它？

## 六步分析链路

### 1️⃣ 定位板块周期
判断当前板块所处阶段：
- **需求爆发**（AI 算力、新能源渗透率）
- **技术跃迁**（CPO/硅光、先进封装）
- **供给受限**（材料纯度、设备交期）

### 2️⃣ 溯源供应链
按层级拆解，从下游到上游：
```
下游需求 → 系统集成 → 模块/子系统 → 芯片/器件 → 工艺/封装 → 设备/测试 → 材料/耗材 → 基础设施
```

目标：找到哪个环节最难扩产、最不可替代。

### 3️⃣ 找候选人
沿供应链层级找 A 股/H股/美股标的：
- 低供应商数量（全球仅 2~3 家能做）
- 长验证周期（认证需要 1~3 年）
- 扩产困难（设备交期长、环评/能评难、材料纯度要求极高）
- 客户认证严格（一旦进入供应链不容易被踢出）
- 技术壁垒高（know-how 积累时间长）

### 4️⃣ 真伪筛选
区分"真瓶颈"和"蹭热点"：

| 真瓶颈 | 蹭热点 |
|--------|--------|
| 产能利用率 90%+，扩产要 12-24 个月 | 故事很热但还缺订单证据 |
| 客户认证已完成，进入供应链 | 只能说"可能受益" |
| 毛利率持续提升（定价权体现） | 收入还没看到变化 |
| 营收和行业需求同向变动 | 收入和行业热度脱钩 |

### 5️⃣ 多空确认

| 做多信号 | 做空/警惕信号 |
|----------|-------------|
| 产能逼近满产，扩产计划确定 | 新技术导致现有技术路线被替代 |
| 客户锁定长单或预付款 | 竞争对手快速扩产 |
| 毛利率持续上升 | 当前股价已透支 3 年增长 |
| 管理层指引上调 | 核心客户开始自研 |

### 6️⃣ 输出研究清单
最终产出格式：
```
优先研究层级：[层级1]、[层级2]、[层级3]

候选标的：
1. [公司A]：卡在[具体环节]，上涨逻辑来自[产能紧张/客户验证/国产替代]。
   证据：[公告/财报/订单/客户认证]
   风险：[替代技术/竞争/估值]

下一步检查：
1. [公司A]最新财报[关键业务]收入和毛利率变化
2. [公司B]有没有新的客户认证或扩产公告
```

## 证据标准

| 等级 | 来源 |
|------|------|
| ✅ 强 | 公告、交易所文件、财报、电话会、监管/项目文件 |
| ⬜ 中 | 可信媒体、行业刊物、专业分析 |
| ⚠️ 弱 | 社交媒体、KOL 帖子（作为线索，不能作为判断依据） |

> **原则：** 社交媒体内容适合作为线索来源，最终判断回到更强证据。
> **A 股特有来源：** 年报/半年报/季报、临时公告、交易所问询函、互动易/上证e互动、招投标、环评/能评、地方项目备案、专利、客户认证、海关数据、应收/存货/现金流、关联交易。

## 关键局限（必须知道）

1. **Serenity 原版战绩在美股**，小盘股波动极大（单日 20-30%），A股版需要适配（政策风险、流动性）
2. **供应链信息真伪难辨**，需独立验证，不能靠 KOL 一句话就买入
3. **逻辑验证需要时间**（1-3 年），不是短线战法
4. **A 股受政策影响显著**，需密切关注监管动态
