# 自我访谈APP V2：四体系行动指南

## 产品逻辑

63题访谈 → 7维度画像 → 四套哲学体系精准匹配 → 3-5张行动卡

```
自我画像（63题）
    ↓
LLM 生成 profile（矛盾点 → 7维度模式总结）
    ↓
action-guide.py 引擎匹配
    ↓
易经 ☯ → 决策逻辑/能力图谱（处境诊断 + 10卦模板）
王阳明 🫀 → 学习成长/防御机制（知行合一 + 事上练）
道德经 🌊 → 价值观动机/防御机制（做减法 + 松绑）
儒家 📜 → 人际交往/家庭身份（角色定位 + 关系导航）
```

每张行动卡结构：处境诊断 → 哲学镜照 → 本周一事（<30分钟）→ 检验信号

## 技术实现

- **引擎**：`app/lib/engine/action-guide.py`（纯规则驱动，零 LLM 成本，25KB）
- **API**：`POST /api/action-guide/generate` → 接受 sessionId，自动拉回答 → LLM 生成 profile → 引擎匹配 → 返回卡片
- **前端**：`CompletePanel` 组件，三种状态：按钮 → loading spinner → 卡片展示

## 易经10卦模板

| 卦 | 处境 | 对位 |
|----|------|------|
| 需卦 | 等待观望期 | D1 逃避模式 |
| 乾卦 | 全力出击期（注意亢龙有悔）| D1 冲动模式 |
| 坤卦 | 跟随辅佐期 | D1 外部依赖 |
| 革卦 | 变革转换期 | D6 能力不匹配 |
| 屯卦 | 初创困难期（默认）| - |

## 数据库新增

- `getAnswer(sessionId, questionId)` — 单题回答查询
- `getAllAnswers(sessionId)` — 全量回答拉取（用于 profile 生成）
