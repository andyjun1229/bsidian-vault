# AI Agent 精确表达训练体系

## 是什么

不是学更多知识，是把已经知道的东西说到能让人按你说的实现。教练不问"你知不知道"，只追问"你能不能讲清楚"。

## 当前进度（截至 2026-08-17）

### 概念 1：Agent 是什么 ✅

- **1/4 精确定义：** 流程控制权在谁手里。聊天机器人你推一步它动一步，Agent 你给目标它自己决定每一步。
- **2/4 边界：** 自动完成（搜索引擎）和接 LLM 的脚本都不算——有自主决策才是 Agent。
- **3/4 纠错：** 大多数人把"自动执行固定流程"当成 Agent。真正的 Agent 每一步后有自主判断。
- **4/4 深入浅出：** 搬家 vs 装修——搬家你说一句他搬一下，装修你说一次目标他跑完全程。

### 概念 2：Agent Loop ✅（2026-08-17 四层全过）

- **1/4 精确定义：** 感知 → 思考 → 执行 → 回到感知。循环和终止都由 Think 判断已完成驱动。
- **2/4 边界：** Think 是推理式的，不是查表式的。Python脚本+LLM、客服QA、RPA 都不是——流程写死，没有自主判断。
- **3/4 纠错：** 大多数人把"自动化流水线"当成 Agent Loop。区别不在有没有调 LLM，而在流程控制权在谁手里。脚本控制流程 vs Agent 自己控制流程——预设路线的自动驾驶 vs 只给目的地的自由行。
- **4/4 深入浅出：** 停是 Think 动手前判断好的，不是执行后被动发现（判断 vs 发现）。日常语言：拿到任务→思考规划路线图→按图施工→施工到图纸最后一步自行喊停。踩过的坑：第四层又滑回"做完看到结果才停"（第一层已纠正过的错误），说明"停=外部触发"这个直觉最顽固。
