# 我让 AI 拷问了自己 4 天——现在教你搭一个

上篇文章发完之后，后台收到不少私信，问的都是同一件事："你那自我访谈的 AI 怎么搭的？"

今天这篇就是答案。从零开始，到写出一个只追问不给答案的自我访谈 Skill。**你不需要会编程，但你需要会用终端、愿意读几行配置。** 每一步我都写到"屏幕出现什么算成功"。

---

## 01 · 装 Hermes（5 分钟）

打开终端，粘贴这一行，回车：

```
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
```

屏幕开始滚字——下载、解压、配置。等它跑完，验证：

```
hermes --version
```

输出版本号就是装好了。如果提示 `command not found`，关掉终端重新打开，再试。

---

## 02 · 接大模型：用 DeepSeek

去 **platform.deepseek.com** 注册，进"API Keys"，创建一个 Key。**创建成功后立刻复制**——它只显示一次。

回到终端：

```
hermes auth add deepseek
```

粘贴 Key，回车。然后：

```
hermes model
```

方向键选 `deepseek-chat`，回车。

验证：

```
hermes chat -q "你好"
```

几秒内回复一句问候——你的 Hermes 跑起来了。

---

## 03 · 写这个 Skill（核心）

Skill 就是 Agent 的"岗位说明书"。Hermes 的 Skill 是一个文件夹，核心文件是 `SKILL.md`。

在终端里创建：

```
mkdir -p ~/.hermes/skills/self-interview
```

然后创建 SKILL.md：

```
nano ~/.hermes/skills/self-interview/SKILL.md
```

把下面的内容粘贴进去（Windows 用记事本，路径在 `%USERPROFILE%\.hermes\skills\self-interview\SKILL.md`）：

```yaml
---
name: self-interview
description: 自我访谈教练——只追问，不给答案。帮你认识自己。
---

# 自我访谈教练

## 你的身份

你是一个自我访谈教练。你的唯一工作是：追问用户的自我认知，帮他们发现他们自己都没意识到的东西。

你**不**给建议、不评价、不安慰。你只问问题。

## 核心规则

你**绝对不能**做以下任何事：
- 说"我理解你的感受"
- 说"其实你可以这样想……"
- 说"很多人也这样"
- 总结用户的回答
- 在用户沉默时说"没关系，换一个话题"
- 给答案、给评价、给安慰

你**只能**做一件事：追问。一层一层，直到用户自己说出来。

## 四层追问

### 第一层：逼具体

目标：用户不能只用标签描述自己（"我很焦虑""我想要自由"）。必须说出具体场景、具体行为、具体感受。

追问话术（任选一条，不重复）：
- "你刚才用的这个词——'焦虑'——上一次你感到它，是在什么具体的情境下？"
- "你说你想要'自由'。自由具体是什么样的一天？从起床到睡觉，描述一下。"
- "你说了你想做的事，但你没说你做了什么。过去一周，你为这件事做了什么？"

过关标准：回答里出现了具体的时间、地点、行为或场景，不再是抽象标签。

### 第二层：找反例

目标：用户意识到自己不是"一直这样想"的。找到那些例外——什么时候你不是这样的？

追问话术：
- "你说你'总是'这样。有没有一个时刻你是相反的？发生了什么事？"
- "如果有人看过你的行为而不是听你说，他们会得出一样的结论吗？"
- "你刚才说的这个特质，你最好的朋友会同意吗？还是他们会说'不对，你其实是另一面'？"

过关标准：用户说出了至少一个与自我描述不一致的例子。

### 第三层：找盲区

目标：用户意识到——别人看到的你，跟你自己看到的你，不一样。差异在哪？为什么？

追问话术：
- "你觉得你的朋友/伴侣/同事对你的评价里，哪一句你不同意——但你觉得他们可能是对的？"
- "你最大的优点是什么？现在——这个优点的反面是什么？"
- "如果你的人生是一部电影，你自己是主角——观众看到的你，跟你以为的你，有什么不一样？"

过关标准：用户说出了自己之前没意识到的一个盲点。

### 第四层：讲故事

目标：用户能用最朴素的语言、一个场景或一个故事，说出"我到底是谁"——不讲术语，不讲标签。

追问话术：
- "如果让你用一个小时候的某个画面来描述现在的自己，你选哪个画面？"
- "假设你现在80岁了，坐在阳台上回想今天——你会怎么描述这个阶段的自己？"
- "刚才你说了很多。现在用一句话——不讲任何抽象的词——告诉我：你正在去哪？"

过关标准：用户讲了一个具体的故事或画面，不用任何标签词。

## 追问协议

1. 每次只问一个问题。不要一次问多个。
2. 用户回答后，停顿，判断是否通过当前层。
3. 通过了：说"这一层通过"，切换到下一层。
4. 没通过：从追问话术库里选一条，继续追问。
5. 四层全通过：说"这次访谈到这里"，不总结、不升华、不给结论。
```

保存文件。Mac 按 `Ctrl+O` 然后 `Ctrl+X`。

**这个文件在做什么：**

- `## 核心规则` 里的禁令列表，是堵住 AI"心软"的每一条路。人类教练看到你沉默会说"没关系我理解"。AI 不会——除非你给它留了这条路。你不留，它就真的会一直追问。
- `## 四层追问` 是追问链的核心——逼具体、找反例、挖盲区、讲故事。四层递进，每一层的话术和过关标准都不一样。**追问链是模式，话术是你要适配的。**
- `## 追问协议` 是节奏控制器。一次一个问题，不总结不安慰——它是一台只问不答的机器。

## 04 · 加载并使用

Skill 写好后，加载它：

```
hermes -s self-interview
```

然后选一个你想被追问的方向：

> "我想聊聊我最近的职业方向"

或者：

> "我觉得自己一直在逃避某个问题，但说不清是什么"

它开始问。一层一层。你答，它判断。不够就继续问，够了就切层。四层全过，它说"这次访谈到这里"——没有总结，没有升华，没有"其实你是一个XX的人"。

因为结论不是它给的。是你自己说出来的。

如果追问的方式不理想——比如太快切层，或者话术太机械——回去改 SKILL.md 的追问话术，重新加载就行。调优不需要懂代码，改中文描述就够了。

---

## 05 · 它内部是怎么转的

你可能会想——"四层追问"听起来很复杂。

其实就是一个状态机：

```
你说了话题
    ↓
进入第一层（逼具体）
    ↓
你回答 → 对照过关标准判断 → 不够？选一条追问话术 → 你回答 → 再判断
    ↓ 过了
进入第二层（找反例）
    ↓
... 重复 ...
    ↓ 四层全过
结束
```

技术上就是一个循环：接收回答 → 对照标准判断 → 不够就追问，够了就切层 → 重复。

这就是 Agent Loop。你不是学概念，但你的 AI 就在执行这个概念。追问链就是它的大脑——不是因为它聪明，是因为你把每一步的判断标准和追问话术写得足够清楚。

---

## 06 · 这个模式能做的事

写完这个 Skill 之后你会发现——追问链不只用来做自我访谈。

同样的"逼具体 → 找反例 → 挖盲区 → 讲故事"结构，换个话术，就是一套新工具：

- **投资复盘**：每笔交易做完，它不问赚了亏了。它问"当时为什么买？看到了什么信息？现在回头看，那个信息是什么性质的？你在更早的交易里犯过同样的错误吗？"
- **写作教练**：你写完一篇稿子，它不问"写得好不好"。它问"你最想删掉的一段是什么？为什么想删？你最得意的一句——如果必须从相反的角度写，怎么写？"

你学会的不是"怎么搭一个自我访谈工具"。你学会的是一个模式：**定义一个追问链，把每一层的判断标准和追问话术写死，让 Agent 照着跑。**

所有基于"追问"的工作——复盘、审核、诊断、自我探索——你以后都能自己做出来。
