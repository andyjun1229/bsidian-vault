## 学到的核心组件

### 1. SVG 流程图封面
- 用 SVG 直接画：主标题 + 副标题 + 右侧流程节点
- 节点用圆角矩形 + 圆形数字标 + 标题 + 英文标签
- 节点之间用 path 连线，输出节点用实心蓝色块
- 底部三个场景胶囊标签
- **关键坑**：微信对 SMIL 动画（`<animate>`）支持差，组件库要写静态版本

### 2. 横向滑动目录卡片
- 顶部一行：左侧 `N PARTS · CONTENT MAP`，右侧 `左右滑动`
- 第一个卡片蓝色渐变背景，其余白色浅蓝边框
- 每张卡片：PART 编号 + 中文标题 + 英文/副标题
- 用 inline-block + `overflow:auto hidden` 实现横向滑动

### 3. 大号章节编号标题
- 左侧超大数字 `01`，下方小字 `PART`
- 竖线分隔
- 右侧：中文标题（19px 900 字重）+ 英文副标题（10px 蓝色浅字）
- 上下 margin 较大（38px 0 26px）

### 4. CASE 标签
- 左侧 3px 蓝色竖条
- 小字 `CASE 01` + 大标题
- 用于案例/场景段落

### 5. Prompt 卡片
- 顶部标题栏：左侧 `PROMPT 01 · COPY READY`，右侧提示词名称
- 标题栏背景浅蓝 `#EFF6FF`，底部边框 `#DBEAFE`
- 内容区等宽字体，字号 12px，行高 1.75

### 6. 蓝色下划线正文标记
- `border-bottom:2px solid #BFDBFE;font-weight:600;`
- 用于产品名、功能名、关键词
- 与飞叔AI沉思录的「深蓝加粗无下划线」不同，这是豆包蓝的默认标记层
