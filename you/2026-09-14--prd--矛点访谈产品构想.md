# 「矛点访谈」——杨天真框架 × 四层追问引擎

## 缘起（三个信号叠加）

1. **需求方亲自下场验证**：杨天真在《长谈》Ep63（9.2万播放）公开两个动作——用 AI 做自我剖析（「把内心纠结层层展开，它替我层层剖析，非常有帮助」）、正在研发「帮每个人找到自己优势的测评系统」。评论区高频问题：「她用的心理 AI 是什么」。
2. **我的资产现成**：self-interview 四层追问引擎（63题）+ DeepTalk Self 已上线 + 零门槛豆包版公式（咒语+显式规则+结构化导出+自救表）。
3. **内容飞轮现成**：这期播客本身就是公众号选题富矿。

## 从播客提炼的产品化素材（杨天真验证过的判据）

| 判据/机制 | 原话依据 | 产品化用途 |
|------|------|------|
| 优势=轻巧就能完成的事 | 「如果它不是轻巧就可以完成的事情，这个就不叫优势」 | 优势识别的过滤器：问「什么事你做起来比别人省力且不自知」 |
| 能量记账 | 「这件事是给我能量加分的还是压制我的」「每月给不想吃的饭一个名额」 | 日常审计机制：能量加分/减分清单 |
| 矛点/对立面 | 「有对立面才能展现你是谁」「人生故事=面对问题的真实态度和过程」 | 找到个人叙事的传播锚点 |
| 自我欺骗探测 | 「我坚定相信我没有自我欺骗→后来发现它埋藏很深，连自己都信」 | 四层追问第4层（动机）的判据：说话越笃定越要挖 |
| 确认来源解绑 | 「解铃人未必是系铃人，不必执着特定的人给我确认」（孙悟空典故） | 治「等待父母/伴侣认可」的执念 |
| 阶段论 | 「向世界证明自己是必经阶段，完成后才有底层自信」 | 判断用户所处阶段，定制追问策略 |
| 方法论迁移 | 「人应从已有职业经历总结方法论，用于上升期行业」「触类旁通=方法论总结+迁移应用，可学习」 | 职场人刚需输出物 |
| 观察者视角 | 「我看见我愤怒了，但不沉溺于情绪之中」 | 情绪觉察的入口话术 |

## 产品定义

**一句话**：用杨天真验证过的判据升级我的四层追问引擎，把「问卷测评给标签」变成「AI访谈给证据链」——产出你的《个人优势地图 + 人生矛点 + 能量清单》。

**核心循环**：
```
访谈挖证据链（四层追问：事实→感受→模式→动机）
  → 判据过滤（轻巧？能量加分？有对立面？）
  → 结构化导出（沿用豆包版公式）：
     3个轻巧优势（附证据）+ 1个矛点 + 能量Top3/减分Top3 + 1条可迁移方法论
  → 存档可复访（季度对照，接 DeepTalk 的档案能力）
```

**目标用户**：职场3-10年、感觉「被卡住」但说不清卡在哪的人。比杨天真测评系统的目标（大众泛流量）更深一层。

## 与现有资产的关系（不新起APP，加模块）

- DeepTalk Self 新增「矛点访谈」模式（v2 核心，技术增量小：就是新题库+新判据+新导出模板）
- 同时出零门槛豆包版（照抄 9/15 那套公式：400字咒语+显式规则+导出指令+自救表），用于公众号获客
- 「零门槛自我访谈包」是它的兄产品：63题版管「认清自己」，矛点版管「找到优势方向」

## 差异化壁垒

- 杨天真做的是**问卷测评**→输出标签（「你是XX型」）；我做的是**访谈证据链**→输出「你在X年做Y事时，别人夸Z，你自己没当回事」。标签可被抄，证据链不可被抄（因为它是从用户自己嘴里挖出来的）。
- 内容壁垒：我手里有她的完整访谈文字稿 + 我的63题实践 + 公众号持续案例产出。

## 商业路径

豆包零门槛版（免费获客，文末钩子「回复【矛点】领咒语」）→ 公众号案例文《杨天真在偷偷用AI认识自己，我照她的方法做了个访谈工具》→ DeepTalk 完整版 → AI知识库训练营模块 → 写书素材。

## 风险

- 杨天真若把测评系统做大，会吸走大众流量 → 应对：她吸流量我做深度，她的话题每一次上热搜都是我的免费获客素材（蹭名人公开话题做二创完全合规）
- whisper 文字稿有错别字，引用金句时以音频/官方为准
