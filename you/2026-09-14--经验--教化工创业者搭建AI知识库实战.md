# 教化工创业者搭建AI知识库实战记录

## 做了什么

把我的个人知识库三件套（Obsidian + 智谱GLM API + Hermes）教给好友雷明（化工创业者，萘环产品，武汉萘星光电）。2026-08-25 启动，前后约 3 周，他从 AI 小白变成每天倒腾 1-2 小时的深度用户。

时间线：
- 8/25 微信给出三步清单：装 Obsidian、搞 API Key（推荐 DeepSeek 充50）、装 Hermes
- 8/29 咖啡馆当面装机：Windows 安装失败（Git 下载连不上、ZIP 失败）——他在我演示后自己用 **WorkBuddy 全程接盘装完了 Hermes**
- 8/30-9/4 他用 WorkBuddy 搭出个人工作台，「强的可怕」
- 9/9 我测试面壁 2B 端侧模型 + 帮他排查内存问题（WorkBuddy 一次性给出专业诊断）
- 9/11-9/13 他用智能体生成萘环行业报告，「比工作台还上头」

## 学到什么（关键观察）

1. **小白的最优学习路径是先动手再补逻辑**。他原话：「我先用，最后再去补底层逻辑。」我原来的方案（讲架构→装机→使用）对他太重了，直接给清单让他跑起来才是对的。
2. **认知跃迁发生在智能体「自己干活」的那一刻**：WorkBuddy 卡住时自己诊断、给方案——「你稍微把诉求说清楚点，他都理解」。对话AI给答案，智能体给结果，这条分界线他一次就感受到了。
3. **工具选择上腾讯系上手快**（视频教程多、每日积分羊毛），Hermes 开源无中间层但 Windows 安装体验差。对小白，先用 WorkBuddy 建立体感，完全正确。
4. **顺手展示就能验证需求**：他给同行看了一眼自己工作台截图，对方愿出 2 万（一次性付款）买同款。B端需求不需要复杂调研，产品做出来在圈子里晃一下就有答案。
5. **不同老板的认知分层很真实**：赵彪只关心业务量（「搞杂事自己搞搞就行」）、老黄对知识库扩边界感兴趣但认为「锦上添花」、雷明本人是强需求（因为他一个人就是全部业务）。卖 AI 方案要找「老板即一线员工」的小公司。

## 商业启发

- 雷明点醒我的定价逻辑：老板要看到 10 倍回报才心动；「员工省下的时间不会自动变成利润」——个人价值已发生、组织价值未兑现，这正是 B 端付费的卡点（9/14 公众号文章同款逻辑）
- 他的核心诉求排序：解决杂事（强需求）< 知识库无限扩充（他最看重）< 实验室智能控制
- FTE 模式升级的构想有价值：从「一个人头一次计费」到「你要啥我给啥，按任务付费」，agent 速度起来后不用驻场投人
