# 零门槛自我访谈包（豆包版）· 知识库存档

> 起因：2026-09-15 粉丝反馈"不会装智能体，能不能直接给我访谈问题"。由此设计零安装方案。
> 完整用户版在家目录：/Users/pilot/自我访谈零门槛包_豆包版.md

## 设计思路（为什么这么做）

1. **载体降维**：Hermes/Claude Code 对普通人是门槛，豆包 App 是零门槛（手机有就行、免费、中文好）
2. **把 skill 压缩成一段咒语**：self-interview skill 的核心不是代码，是四层追问逻辑——四层目标+过关判据+违规禁令可以完整塞进一条 prompt（约400字）
3. **把"工程化质检"翻译成"人话规则"**：skill 里的过关判据（出现具体时间/地点=第一层过）直接写成豆包可执行的显式规则，不依赖模型自觉
4. **"导出"指令 = 简易 findings 表**：仿花叔数据表思路，访谈结束强制产出结构化总结（5金句/3盲区/2反例/3遗留问题），让访谈可积累、可复访

## 核心交付物

一段可复制的开场咒语（400字）+ 一段导出指令 + 翻车自救话术表（5条）

## 可复用公式（其他 skill 零门槛化时照抄）

**Skill → 大众版 = 核心逻辑写成咒语 + 判据写成显式规则 + 结尾强制结构化导出 + 翻车自救表**

## 公众号选题潜力

《不会装智能体也能做自我访谈：一段咒语 + 一个豆包，40 分钟认清自己》
- 痛点：想试 AI 自我访谈但卡在安装
- 交付：咒语直接复制（文末钩子：回复【访谈】领完整包）
- 进阶钩子：季度复访对照机制（留存）
