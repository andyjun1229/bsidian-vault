# 六大AI博主文风解剖 v2——20篇交叉验证版

> 2026-09-18。v1 单篇印象 → v2 全量精读交叉验证（花叔×3、甲木×4、小李×2、机器之心×3、DeepTech×2、卡兹克×1+转述、飞叔自写×1）。关键发现：vault 里飞叔自己的原文（K3 一篇）是「飞叔体」的最佳锚点。

## 1. 卡兹克——悬念叙事体

**样本**：Jev 一篇全文（raw/2026-09-18）
**人设**：带你围观的发烧友，跟你平坐，不教你
**开头**：悬念递进，短句成段——「这两天，如果说最火的大模型是什么，那可能只有一个名字。Jev.」（名字单独成段制造停顿）
**标志手法**：
- 耳语感：「相信我」「可能听起来还是有点玄乎」「这就是 Jev 最奇怪，也最性感的地方」
- 生活化类比轰炸：买衣服/打 Boss 格挡闪避/彩礼给不给——抽象概念砸进日常
- 亲测背书：自己的产品真拿去测，四模型对比出数据（GLM 全对但最贵、Jev 综合最优、Qwen 便宜但差 7 个点）
- 设问推进：「AI，为什么一定要生成东西？」
**结构**：悬念命名 → 反常识（它只会做选择题）→ 别人拿它干了什么 → 亲测对比 → 名字隐喻（杰文斯悖论）→ 升华收尾
**可偷**：一句话一段的节奏；类比轰炸；「我自己第一时间测了」

## 2. 花叔——工程师实验体

**样本**：LibTV 评测原文 + huashu-report 笔记
**人设**：拿三支片子验货的较真评测人，每个判断必须有亲手实验托底
**开头**：具象到夸张的结果场景——「在纽约中央公园拍了一张松鼠扒星巴克冰咖啡的照片…21 分钟后拿到成片」
**标志手法**：
- 判断挂实验：不说「它很智能」，说「Agent 认出松鼠、绿吸管冰饮料、米白托特包，只问了一个问题：横屏还是竖屏」
- 细节颗粒度：星巴克 logo 还原到能直接进广告、分镜草图标着「极端大特写，荷兰角 15 度倾斜」
- 规则工程化思维（huashu-report 笔记证实）：「能写成函数或计数的规则，就不要留在手册里」「口径写不出一句完整的话，这个数字就不能用」——文风只是这个思维方式的外显
- 结构分层强迫症：三层架构表格、流程 8 步编号、「关键感受」小节
**结构**：具象结果 → 工作流程拆步 → 架构分层 → 核心价值判断 → 再来一个实验
**可偷**：判断必挂亲手实验；细节颗粒度；先亮结果再拆过程

## 3. 甲木未来派——教练陪跑体（4 篇交叉）

**人设**：隔壁踩过坑的教练，每次开讲先接上集
**标题公式**：实用承诺型——「搞懂这三件事，很多活就能用XX秒杀了（送官方福利）」「分享一个XX，助你实现XX自由！」「开源一个XX｜彻底解决XX难题（建议收藏！）」
**开头**：「大家好啊，我是甲木。」+ 接上篇（「前天刚跟大家聊过」）+ **读者反馈选题**（「翻了翻后台，发现还是有些概念容易让人混淆」）+ 设问钩子独立成行（「发布前最烦的那一个小时？」）
**标志手法**：
- CASE 字段化：CASE 01-04，每案例固定字段（用到的 Skill / 提示词原文 / Agent 工作流程编号 / 修复过程）
- 双语小标签（KNOW SELF / LEARN CASES）、内容地图前置（4 PARTS）
- 口语过渡：「好，进正题」「先补两个最值得单独说一嘴的」
- 完整签名：「我是甲木，热衷于分享一些 AI 干货内容，同时也会分享 AI 在各行业的落地应用。觉得有用的话，点个赞、在看、转发三连，谢谢大家。」+「以上。」+ 福利 +「敬请期待~」
- 观点收尾挂引用块
**可偷**：选题从后台问题来；连载感；CASE 字段化；Prompt 给可复制版

## 4. 摸鱼小李——结果前置体

**样本**：完整版 5171 字 + 摘录版
**人设**：帮你把复杂装进 20 分钟的老朋友，给工具起外号（OpenClaw=龙虾）
**开头**：结论+时间承诺砸脸——「2026 年最顺手的知识管理三件套，OPC 必备」「20 分钟装好全套」+ 续集感（「好多朋友看完直接重新下回了 OB」）
**标志手法**：
- 先看效果再教安装：01 章全是真实生活场景 Case（刷小红书拆爆款、等桌时调研）
- 双语装饰流程行：「孤立信息 → 4 STEPS → 个人智慧 / 收集✓→整理✓→创作✓→分享✓」
- 交付物到对话级：连「给龙虾发这段话」的原文都给出
- 完整签名：「好啦，本期就到这，我是摸鱼小李，感谢关注。三件套配齐了吗？遇到问题评论区聊聊👇」+「下期单独讲」
**可偷**：效果前置于方法；场景是真实生活切片；工具爱称；互动收尾

## 5. 机器之心——机构情报体（3 篇交叉，最长 12233 字）

**人设**：无「我」的全知观察者
**开头**：一句话悬念零废话——「一笔融资、一份技术报告，让一个过去五年鲜少公开发声的团队，逐渐显露出更完整的面貌」
**标志手法**：
- 「不是A而是B」判断句：「它做的不是把论文网站搬到命令行，而是把科技文献本身转化为智能体可以直接消费的数据接口与技能系统。」
- 信号并置对仗：「通用大模型公司开始组织生物实验，生物模型公司开始招聘大模型人才」
- 小数点精确：76.2% vs 75.6%
- 短判断句收段：「两条路线正在靠近。」
**可偷**：对仗句出判断；小数点精确；短判断句顿挫（机构腔不能学——飞叔体必须有「我」）

## 6. DeepTech深科技——具象开场报道体

**开头**：具象画面——「只用 3 部固定在三脚架上的 iPhone，Atlas 就能重现《黑客帝国》式的子弹时间」
**标志手法**：场景先行；引语驱动（观点挂在人身上）；大词锚点（全球首个）；参考资料/图注规范
**可偷**：具象画面开场；观点挂具体的人说的话

## 7. ⭐ 横向底层共识（「不 AI」的秘诀）

1. 开头 3 句内必有钩子（悬念名/具象场景/结论承诺/读者反馈）——没有一家用「最近我研究了XX」起手
2. 判断必挂证据：花叔的实验、卡兹克的亲测、机器之门的数据——没有裸观点
3. 句长错落：短句独立成段制造停顿，没有匀速长句流
4. 人味小设计：外号、福利、接上集、跟读者对话
5. 结构可见：读者任何时刻知道读到哪了

## 8. ⭐ 关键发现：飞叔自己的声音（K3 一篇）

vault 里《K3 开源震惊世界，但我更在意那个不透明的账单》是你自己写的。特征清单就是「飞叔体」的种子：

1. **让步式立场开头**：「开源是好事，K3 也确实强。但作为一个付了费的普通用户，我想聊一件比参数更重要的事。」——先让一步（客观），再亮立场（勇敢）
2. **时间线排比**：7月17日发布/22日白宫指控/24日黄仁勋首条X/27日正式开源——四连击交代背景零废话
3. **短判断句独立成段+首尾重复**：「能力是产品力。透明度也是产品力。」出现两次，钉进读者脑子
4. **为民发声视角**：「作为一个付了费的普通用户」——天然站在小人物一边，对不透明较真
5. **反问收尾**：「你连一个 Token 消耗明细都不给我，我怎么知道我这一周的额度是被什么吃掉的？」
6. **口语化小节标题**：「项目做到三分之二，额度没了」「Kimi 不告诉我，我的钱花在哪了」——标题是人说的话

## 9. 飞叔体 v2 公式

**声音内核**（K3 提取）：较真实践者，为民发声，先让步后亮剑，证据说话，不爽直说。
**技法外挂**（六家提取）：
- 小李：结果前置 + 交付物给到对话级
- 卡兹克：短句成段节奏 + 类比 + 耳语感
- 花叔：判断挂亲测实验 + 细节颗粒度
- 甲木：接上集连载感 + CASE 字段化 + 后台选题
- 机器之心：「不是A而是B」判断句（去机构腔后用）
**密度红线**：每篇至少一个可复制交付物；结构有路标；数据精确不编造。
