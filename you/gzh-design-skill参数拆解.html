一、参数组件（可调/可选，排版时的决策变量）

P1 主题选择参数

来源：SKILL.md 章节「选主题」

参数可选值默认值决策依据
thememoyu-green / red-white / graphite-minimal / zen-whitespace / moyu-ticket / olive-journal / bloom-blue（飞叔）moyu-green（自动推首推）文章题材匹配（教程→摸鱼绿、观点→红白、科技→冰蓝、总结/禅意→留白）

P2 文章结构参数

来源：SKILL.md 章节「解析Markdown结构」「文章类型→组件组合配方」

参数可选值默认值决策依据
article_type观点分析 / 教程指南 / 盘点清单 / 数据复盘 / 访谈特稿 / 经验随笔观点分析步骤和命令多→教程；并列条目多→盘点；数字对比多→数据；论证推演多→观点
core_components正文6 + 金句8 + 居中金句10 / STEP14 + 有序列表13 + 代码块16 / …按文章类型取配方表配方表决定哪些组件是必选的「核心组件组合」
accent_components浅底引用9 / 深蓝竖条11 / 冰蓝线框12 / 图片15 …按文章类型取配方表配方表决定哪些是可选的「点缀组件」
highlight_count≤3个锚点处全文≤3处琥珀黄点睛（F59E0B）的全篇配额，用于最关键锚点
underline_terms每段1-3个关键短语每段必标按语义识别：核心观点、关键数据、专有名词；15字以内

P4 目录/看点参数

P5 章节标题参数

来源：组件4 章节标题 + 组件5 小节标题

参数说明生成规则
chapter_number章节编号 01/02/03…按 `##` 出现顺序自动编号
chapter_english英文标签（实测→TEST、教程→TUTORIAL、总结→SUMMARY）中文标题语义→映射英文标签
chapter_title_zh中文章节标题原文取自 `## 标题`
is_conclusion最后一章是否为结语若末章标题含「结语/总结/写在最后」→编号变体 `∞`

P7 签名区参数

来源：组件19 作者签名 + 组件20 结尾行动区

参数说明取值规则

来源：通用增量库组件 1a/1b + 主题库组件16

P9 图片参数

来源：组件15 图片容器 + 通用库 2a/2b

参数规约
image_caption只有 `![说明](url)` 里真正有说明文字时才生成说明组件；空alt不编造
image_width常规图 `max-width:100%`，不 `width:100%`（防小图拉伸）；流程图/封面卡 `width:100%`
二、校验组件（排版质量的硬约束）

C1 平台禁用检查（validate_gzh_html.py）

检查项规则错误级别
<style>不得出现任何 style 块ERROR
<script>不得出现任何 script 块ERROR
<div>不得使用 div 标签ERROR
class / id不得使用 class 或 id 属性ERROR
position:fixed不得使用 fixed/absolute/stickyERROR
float不得使用 floatERROR
@media / @keyframes不得使用媒体查询或动画ERROR
display:grid不得使用 grid 布局ERROR
CSS var / 外部字体不得使用 CSS 变量或引用外部/CND 字体ERROR
半角标点（WARNING）正文中不得出现半角 , . ! ? : ; 和英文直引号 " 'WARNING（但必须修复到0才能交付）

C2 样式强制检查

检查项规则
<span leaf>所有文字节点必须用 ... 包裹，否则粘贴后样式丢失
内联样式所有样式必须用 style="" 内联，不可引用外部或嵌入式 CSS
display:flex有限可用（三列看点卡、列表项等），不得滥用
linear-gradient可用（荧光笔组件）
border-radius / box-shadow可用

C3 组件合规检查（component_lint.py）

检查项说明
全站覆盖率每个主题组件库必须包含五章节：设计变量速查表、各组件完整HTML、完整文章模板骨架、文章类型配方表、Markdown映射规则表
反模式扫描检查组件库中是否混入 class/id/style块/div/半角标点等平台禁用项
theme-index完整性theme-index.md 每一行必须有：主题名 / 主色 / 适用场景 / 组件库文件 / 正文下划线CSS，缺一不可

C4 内容质量检查（排版过程中的人工决策）

检查项规则
锚点层不超过5处全文最强强调（琥珀黄/冰蓝线框提示/深蓝竖条提示）合计≤5处
下划线不漏段每个正文段落必须标记1-3个关键短语，不能有段标有的段漏
目录是精选不是全量本文看点展示3个核心要点，章节多于3个时挑最重要的3个
不跨主题混用一篇文章只用所选主题+通用库的组件，不从其他主题借组件
签名区唯一全文只有末尾一个签名区；原文末尾自带签名的，合并进去
不编造图片说明空alt的图片不生成说明组件
封面占位图不留签名区/CTA组件里若带名片图占位，没有真实图片URL时整行删掉
代码块紧凑每行 p style="margin:0"；不用 white-space:pre；缩进用全角空格
